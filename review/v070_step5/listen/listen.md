# 카드 소리 후보 d (계획서 33번): 웅장하게, 둔탁하지 않게

**게임에는 d2를 넣었어요** (선택 d2, 등장 d2). 저는 귀로 듣지 못하고 아래 숫자로만 골랐어요. 들어 보시고 d1이 낫거나 섞고 싶으면 알려 주세요.

| 파일 | 내용 |
|---|---|
| `card_pick_d1.ogg` `d2` | 선택 "철-컥". 같은 소리를 3번 |
| `card_show_d1.ogg` `d2` | 등장. 노멀 → 레어 → 에픽 → 유니크 → 레전드리 순서로 이어서 한 파일 |

## 무엇이 다른가

| | d1 금속 앞 (단단함) | d2 화음 앞 (넓고 웅장함) |
|---|---|---|
| 선택의 화음 | F C F C (3음 없는 5도, 단단한 확정) | F Ab C F Ab (단조 3음이 들어감) |
| 금속 울림 | 더 앞에 | 뒤로 조금 |
| 잔향 | 기본 | 1.25배 길고 더 많이 |
| 좌우 폭 | 중간 | 넓게 |
| 금관 필터가 열리는 정도 | 2.6kHz | 3.4kHz (더 밝게 열림) |

## 등급별 층 (두 후보 공통)

| 등급 | 소리 |
|---|---|
| 노멀 | c의 스윽 + 아주 짧은 잔향 |
| 레어 | + 반짝임 F, 얇은 화음(F C) |
| 에픽 | + 반짝임 C→F, 화음 몸통 F C F Ab, 잔향 커짐 |
| 유니크 | 쉬익 0.16초 → 쾅(몸통 + 금속판) + 넓은 F 단조 화음 + 반짝임 |
| 레전드리 | 모임 쉬익 + 올라가는 반짝임 0.34초 → 쾅 + 넓은 Fm7 (F C Ab C Eb Ab, 위가 Ab 장조라 밝음) + 올라가는 반짝임 4음 |

게임에서 유니크의 "쉬익"은 카드가 떨어질 때 시작해서 앞면이 보이는 순간 "쾅"이 맞아요. 건너뛰면 "쾅"만 나요. 다시 뽑기의 레전드리도 유니크처럼 짧은 "쉬익"을 써요.

## 숫자 확인 (`tools/test_make_sfx.py`가 자동으로 확인)

| | 예전 a | 예전 b | c2 | d1 | d2 |
|---|---|---|---|---|---|
| 선택 무게중심 | 373Hz | 487Hz | 2,483Hz | 1,022Hz | 1,051Hz |
| 선택 150~600Hz (몸통) | | | 거의 0 | 20.8% | 34.7% |
| 선택 2~5kHz (또렷함) | | | 30% 넘음 | 13.4% | 18.6% |
| 선택 꼬리 (-30dB까지) | | | 없음 | 0.33초 | 0.36초 |

모든 소리: 80Hz 아래 0.1% 미만. 9kHz 위는 짧은 바람 소리(쉬익) 2% 정도, 나머지 1% 미만. 등급이 오를수록 꼬리가 길어져요 (d2 레어 0.25초, 에픽 0.56초, 유니크 1.00초, 레전드리 1.52초).

**d2를 고른 이유:** 사용자 요청이 "웅장함"이고, 몸통(34.7%)과 좌우 폭이 더 크면서 무게중심은 d1과 비슷해서 더 둔탁해지지 않아요.

다시 만들기: `python3 tools/make_sfx.py --listen5` (게임 파일은 `python3 tools/make_sfx.py`). 이전 후보를 다시 만드는 스크립트는 커밋 b37af5f 기준이에요 (`make_cards_c.py`는 이제 `make_sfx.py`의 등장 데모와 맞지 않아요).

# 카드 소리 후보 c (계획서 32번): 가볍고 산뜻하게

**게임 소리는 그대로예요.** 고르시면 넣어요. 저는 귀로 듣지 못하고 아래 숫자로만 확인했어요.

| 파일 | 내용 |
|---|---|
| `card_pick_c1.ogg` `c2` `c3` | 선택 "착칵". 같은 소리를 3번 (0.14초씩) |
| `card_show_c1.ogg` `c2` `c3` | 등장. 노멀 → 레어 → 에픽 → 유니크 → 레전드리 순서로 이어서 한 파일 |

## 무엇이 다른가 (1이 가장 부드럽고 3이 가장 밝음)

| | c1 부드럽게 | c2 중간 | c3 밝게 |
|---|---|---|---|
| 선택의 금속 음 | 약간 낮게, 윗소리 많이 깎음 | 기준 | 약간 높게, 윗소리 덜 깎음 |
| 스윽의 공기 | 0.9~4.2kHz | 1.2~5.2kHz | 1.5~6.2kHz |
| 반짝임 | 레어 F6(1.4kHz), 위 배음 작음 | 같은 음, 위 배음 중간 | 한 옥타브 위(레어 2.8kHz), 위 배음 큼 |
| 7~8kHz 위 | 6kHz부터 -9dB, 7.5kHz 저역통과 | 7kHz부터 -7dB, 8.5kHz | 8kHz부터 -6dB, 9.5kHz |
| 밝기 숫자(무게중심) 선택 / 등장 | 2,286Hz / 1,543Hz | 2,483Hz / 1,896Hz | 2,735Hz / 3,065Hz |

c2와 c3의 등장 소리는 차이가 커요(반짝임이 한 옥타브 올라감). 선택 소리 세 개의 차이는 그보다 작아요.

## 등급 구분 (세 후보 공통, 낮은 울림 없음)

| 등급 | 스윽 위에 더하는 것 |
|---|---|
| 노멀 | 없음 (스윽 0.11초) |
| 레어 | 반짝 한 번 (F) |
| 에픽 | 반짝 두 번 (C → F) |
| 유니크 | 짧은 밝은 화음을 살짝 펼쳐서 (F Ab C, 0.2초) |
| 레전드리 | 모임 약 0.3초 동안 C Eb F Ab C로 올라가는 반짝임 → 올라가는 음계 4음 (Ab C Eb Ab, 0.43초) |

모두 F 단조 음으로만 만들었어요 (레전드리 음계는 같은 음들로 된 Ab 장조라 밝게 들려요).

## 숫자 확인

| | 예전 a | 예전 b | c1 | c2 | c3 |
|---|---|---|---|---|---|
| 선택: 200Hz 아래 에너지 | 56.6% | 51.3% | 0.00% | 0.00% | 0.00% |
| 등장: 200Hz 아래 에너지 | 58.6% | 57.3% | 0.00% | 0.00% | 0.00% |
| 선택 무게중심 | 373Hz | 487Hz | 2,286Hz | 2,483Hz | 2,735Hz |

예전 소리가 둔탁했던 이유로 보여요: 에너지 절반 이상이 200Hz 아래에 있었어요. c 소리는 8kHz 위 에너지가 어느 소리든 2% 아래이고, 스크립트가 이 조건과 "시작 3ms 안에 또렷해짐", "1 < 2 < 3 순서로 밝아짐"을 실행할 때 확인해요.

크기(LUFS, 파일 전체 평균): 선택 약 -31~-30 (예전 a -28), 등장 약 -27 (예전 a -24). 낮은 음이 빠져 측정값은 낮지만 2~5kHz는 귀에 잘 들려요. 크거나 작으면 고른 뒤 조정해요.

고르신 뒤에는 `make_cards_c.py`의 함수를 `tools/make_sfx.py`로 옮기고 `scripts/sfx.gd`의 크기를 맞춰요.

다시 만들기: `python3 review/v070_step5/listen/make_cards_c.py`

# 이전 후보 a·b (계획서 31번, 사용자: 둘 다 둔탁하고 무거움)

모두 게임 크기로 맞췄고, 4kHz 위를 깎았어요. 저는 귀로 듣지 못하고 길이, 주된 음, 4kHz 위 비율 숫자로만 확인했어요.

## 선택 "철컥" (0.2초 안팎, 같은 소리를 3번)

| 파일 | 만든 방법 | 길이 | 게임 |
|---|---|---|---|
| `card_pick_a.ogg` | 합성. 작은 걸쇠 "철" 뒤 0.05초에 낮은 잠김 "컥" | 0.17초 | **넣음** |
| `card_pick_b.ogg` | Kenney 금속 충돌음(CC0) 2개를 낮춰 겹침. 실제 금속 질감 | 0.18초 | |

## 등장 세트 (노멀 → 레어 → 에픽 → 유니크 → 레전드리 순서로 이어서 한 파일)

| 파일 | 뒤집힘 | 에픽 | 유니크 | 레전드리 펼침 | 게임 |
|---|---|---|---|---|---|
| `card_show_a.ogg` | 부드러운 바람 + 약한 금속판 | F 단조 화음 (F3 C4 Ab4) | F2 + C3로 깔리는 "웅" | F4 Ab4 C5 F5 (F 단조) | **넣음** |
| `card_show_b.ogg` | 금속판이 더 또렷함 | Ab 장조 쪽 (Ab3 Eb4 C5) | F2 + F3 "웅" | Ab4 C5 Eb5 Ab5 (Ab 장조, 더 밝음) | |

레어는 짧은 반짝임 두 음이에요. 레전드리는 앞에 0.3초 오르는 모임 소리(F3→F5)가 있어요.

**고른 이유:** 높은 소리를 싫어하신다고 해서, 금속성이 약하고 배경음과 같은 F 단조인 a로 넣었어요. b가 더 좋으면 `tools/make_sfx.py`의 `CARD_CHOICE`만 바꾸고 다시 실행하면 돼요.

다시 만들기: `python3 tools/make_sfx.py --listen4`
