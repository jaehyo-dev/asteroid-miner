# 4c 버벅임·성능 측정

측정 코드: `probe.gd.txt` (임시 복사본에만 넣음, 게임에는 없음). 전 = 4b 커밋 f5ce300 기준 코드, 후 = 4c.
"후"에는 새 배경음 재생 비용도 포함돼요. 스레드 없는 웹 빌드라 소리 섞기도 메인 스레드에서 돌아요.

## 1. 2분 30초 버벅임 원인

방법: 웹 내보내기를 Chromium에서 실행. (가) 0초부터 실제로 175초 진행(소프트웨어 그리기), (나) 140초까지 빨리 감은 뒤 30초 진행(Apple M3 GPU). 큰 운석이 깨진 프레임과 40ms 넘는 프레임의 구간별 시간을 기록.

| 원인 후보 | 측정 (CPU 4배 느림) | 판단 | 조치 |
|---|---|---|---|
| 쌓인 광물로 늘어난 그리기 호출 | 시작 약 30번 → 2분 30초 300~500번 (광물 하나당 원 2개가 호출 2번) | **주원인.** "2분 후반부터"라는 시점과 맞음 | 아틀라스로 묶음: 340 → 60번 |
| 소리 동시 재생 (ogg 시작 비용) | 큰 운석 프레임 평균 5.7ms, 최대 9.3ms. 0~175초 진행 중 최대 26.5ms | **주원인.** 깨지는 순간과 정확히 겹침 | wav로 바꾸고 겹침 수 줄임: 평균 약 1.7ms, 최대 2.5ms |
| 히트스톱 (의도한 멈춤) | 큰 운석마다 40ms 멈춤. 후반에 연달아 걸림 | **원인.** 이어지면 멈칫거림으로 보임 | 끝난 뒤 0.4초 안에는 다시 걸지 않음(황금 운석 제외). 흔들림은 유지 |
| 파편·광물 한꺼번에 생성 | world.step 평균 1.2ms | 작음 | 조치 없음 (파편은 4b에 풀·상한을 넣음) |
| 첫 사용 비용 (셰이더, 글자, 그림 첫 로드) | 소프트웨어 그리기에서 첫 포격 예고·게이트 때 80~130ms. M3 GPU 전: 최대 166ms, 후: 없음 | 판 초반 한 번씩이라 2분 30초의 원인은 아님 | 아틀라스를 판 시작 때 불러오고 시트를 따로 불러오지 않음. 소프트웨어 그리기·실제 폰에서는 **다시 재지 않음** |

그 밖에 처리 시간이 작은데 50~190ms로 튀는 프레임이 소프트웨어 그리기에서 많았어요. 사건과 상관없이 나타나 headless 브라우저의 잡음으로 보고, M3 GPU 측정에서는 나타나지 않았어요.

2분 30초 상황 (나, M3 GPU):

| CPU | | 평균 ms | 최대 ms | 33ms 넘은 프레임 | Godot 처리 ms | 그리기 호출 |
|---|---|---|---|---|---|---|
| 1배 | 전 | 16.8 | 166.6 | 2 / 1791 | 5.1 | 259 |
| 1배 | 후 | 16.7 | 16.8 | 0 / 1801 | 1.6 | 51 |
| 4배 느림 | 전 | 16.7 | 50.0 | 1 / 1798 | 13.0 | 340 |
| 4배 느림 | 후 | 16.7 | 33.3 | 0 / 1800 | 7.0 | 60 |

- 무작위로 진행되는 판이라 상황이 똑같지는 않아요. 큰 운석이 깨진 횟수가 30초에 1~5번뿐이라 소리 수치는 표본이 적어요 (위 "후"의 소리 수치는 4~5번 깨진 앞선 측정 값).

이 방법은 GPU 없이 CPU로 그려서, 호출을 줄여도 픽셀 칠하는 시간이 그대로라 평균 프레임은 거의 안 변해요. 그래서 실제 GPU로도 쟀어요.

- 방법: 시트 25장과 원·선·사각형을 아틀라스 2장(2048x1540 운석 외, 2048x1152 운석. WebGL2 보장 크기 안)에 넣고 모두 같은 텍스처의 사각형으로 그려요. MultiMesh는 쓰지 않았어요 (사각형 묶음으로 충분하고 코드가 훨씬 적어요).
- 후의 처리 시간 중 절반 이상은 시뮬레이션(약 18~21ms, CPU 4배 느림)이에요. 이 상황은 5발씩 0.05초마다 쏘는 극한이라 시뮬레이션은 건드리지 않았어요.
- **QUALITY_BAR 30 "휴대폰 60fps(가장 많을 때)"는 아직 안 됨**: 극한 상황의 CPU 4배 에뮬레이션은 약 30fps. 2분 30초 실제 상황은 60fps. 실제 폰은 **확인 못 함** → 숨은 FPS 표시로 사용자가 확인.
- 대가: 내보낸 게임 파일(pck) 2.6MB → 4.1MB (아틀라스, wav, 배경음).

## 3. 숨은 FPS 표시

일시 정지 화면 제목 "일시 정지"를 2초 안에 5번 누르면 켜지고 꺼져요. 화면 위 가운데에 `60 FPS · 호출 40`처럼 보여요. `user://settings.cfg`에 저장돼요.
