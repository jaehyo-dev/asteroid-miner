# v0.8.0 4b단계: 보조 무기 단계 연출 확인 자료 (2026-11-12, 맥)

웹 빌드(`?fxtest`)를 Playwright headless(Chromium)로 열어 찍었다. Godot 창은 띄우지 않았다.

- `gif/<무기>_<1|3|5>.gif` 18개: 1280x720(출격 화면 2배), 4초, 15장/초. 기본 무기 펄스 연사포 + 그 보조 무기 하나(Alt+1~6), 촬영 모드(Shift+0: 체력 유지, 우주선 30~80 거리에 운석·해파리 채움, 레벨업 멈춤). 기뢰·톱날은 사각형으로 움직이며 찍었다.
- `sheet_<무기>.png` 6장: 1·3·5단계를 한 줄로 (우주선 둘레 560x360). 칸마다 효과가 잘 보이는 프레임을 골랐다(`picks.json`).
- `perf/`: 폰 844x390 성능 측정 결과와 캡처 2장.
- 다시 만들기: `python3 -m http.server 8765 --directory build/web` → `NODE_PATH=… FRAMES=<폴더> node review/v080_step4b/capture_web.cjs <장면…>` → `python3 review/v080_step4b/make_gifs.py <폴더>`

## 단계별 연출 (2·4단계는 모양 그대로 15% 밝게)

| 보조 무기 | 1단계 | 3단계 | 5단계 |
|---|---|---|---|
| 유도 미사일 포드 | 몸통 6픽셀(예전 1.5배), 빨간 탄두, 가는 회색 연기, 작은 폭발 | 금빛 탄두 + 빛, 불꽃 꼬리 두 줄, 폭발에 충격파 고리 | 붉은 주황 탄두, 흰 점이 섞여 흔들리는 꼬리, 발사 때 우주선 둘레 번쩍임(해치), 폭발 고리 + 불티 10개 |
| 블랙홀 발사기 | 작은 보라 원반, 옅은 테두리 | 자홍 테두리, 가운데를 도는 납작한 점 원반, 끌려 들어가는 먼지 줄기 6개 | 남색 원판 + 흰·청록 테두리 중심, 이어진 나선 팔 3개, 끝날 때 오므라든 뒤 소용돌이 무늬가 퍼지는 붕괴 |
| 궤도 톱날 | 작은 회색 톱날, 이 5개 | 청록 날 끝 6개, 잔상 호(점 4개), 맞으면 불꽃 | 더 큰 톱날, 주황 날 끝 8개, 긴 잔상 호(점 8개), 주황 불꽃 + 운석을 갈면 돌 부스러기 |
| 기뢰 살포기 | 작은 둥근 기뢰, 빨간 불빛 깜빡임 | 가시 4개, 적이 40 안이면 깜빡임 3배, 폭발 고리 | 더 큰 몸통 + 가시 8개, 바닥에 옅은 빨간 경고 원(폭발 반경), 폭발은 불꽃 꽃잎 6장 + 연기 + 고리 |
| 방전 코일 | 가는 파란 번개 | 흰 번개 + 청록 빛, 잔가지, 맞은 대상 흰 번쩍임, 쏠 때 우주선 둘레 전기 고리 | 굵은 흰·청록 번개 + 빛 번짐, 남아 있는 동안 다시 꺾여 지직거림, 정전기 고리가 늘 돎(화면 전체 번쩍임 없음) |
| 채굴 펄스 | 금빛 고리 + 고리를 따라 반짝이는 점 12개, 맞은 운석에 금빛 금 3줄 | 고리 두 겹, 지나간 자리에 육각 격자, 맞은 운석에 빛나는 광맥 4줄 | 고리 세 겹 + 방사선 12줄, 다 퍼진 뒤 잔광 0.5초, 맞은 운석에서 금가루 |

판 화면 칸 아이콘: 3단계부터 아이콘이 밝아지고, 5단계는 오른쪽 위에 금빛 반짝임(테두리 색 아님).

## 검수 (GIF 18개·비교 그림 6장을 하나씩 열어 봄)

- 효과가 보이는지: 18개 모두 그 단계 연출이 보임. 방전 코일 1단계는 번개가 짧고(가까운 대상) 가늘어 4초 중 몇 장에만 보인다(#2, #24 근처). 유도 미사일은 작고 빨라 멈춘 그림보다 GIF로 봐야 잘 보인다.
- 다시 찍은 것: 1차에 레벨업 카드가 6개 장면에 끼어듦 → 촬영 모드를 먼저 켜고, 촬영 모드에서 생긴 레벨업은 바로 지우게 고친 뒤 18개 모두 다시 찍음(카드 0). 블랙홀 5단계(나선 팔이 흩어진 점으로만 보임 → 이어진 선), 기뢰 3·5단계(가시가 몸통에 묻힘 → 바깥으로), 방전 코일 3개(번개가 적 그림 아래에 가려짐 → 내 탄 층으로, 남는 시간 0.22~0.28초) 고친 뒤 다시 찍음.
- 레벨업 카드·잘린 그림·깨진 글자·칸 밖 글자: 없음. 구석 글자는 촬영 모드에서 "채굴 펄스 3단계 / FPS·효과" 두 줄만.
- 크게 하얀·노란 덩어리는 해파리 처치 연출과 처치 번쩍임(예전 그대로)이다. 적 탄과 우주선은 내 효과보다 위에 그려진다.
- 콘솔 오류 0 (모든 촬영).
