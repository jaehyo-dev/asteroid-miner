# 6단계 워프 점프 자료

| 파일 | 내용 |
|---|---|
| `launch.gif` | 출격 (늘이기 없앤 뒤): 이륙 → 충전 → 점프(잔상·빛줄기·속도선·흰 번쩍) → 터널 → 도착 |
| `launch_before.gif` | 출격, 고치기 전 (우주선이 위아래로 늘어남) |
| `launch_compare_slow.gif` | 출격 점프 전(왼쪽)·후(오른쪽), 4배 느리게 |
| `return.gif` | 귀환 (늘이기 없앤 뒤): 게이트 충전 → 점프 → 기지 착륙 → 결과 (캡처에서는 충전 뒤 1.5초만) |
| `return_before.gif` | 귀환, 고치기 전 |
| `return_compare_slow.gif` | 게이트로 빨려 드는 순간 전(왼쪽)·후(오른쪽), 4배 느리게 |
| `gate_before_after.png` | 게이트 전후 비교 |
| `gate_states.gif` | 게이트 등장 → 닫히기 직전 |

다시 만들기: `tools/capture_warp.gd` (머리 주석 참고). 그림은 `tools/make_gate_art.py`, 소리는 `tools/make_sfx.py`.
