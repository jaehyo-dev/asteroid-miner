# v0.8.0 무기 업데이트 계획 (2026-11-11 인터뷰 결정)

GAME_SPEC.md 11장 "v0.8.0 무기 업데이트 인터뷰 결정"의 자세한 계획. "확정"은 사용자 결정, "안"은 Claude가 정한 임시안(첫 단계에서 흐름표와 함께 다시 확인).

## 1. 확정된 결정

| 항목 | 결정 |
|---|---|
| 보조 무기 | 판 안 레벨업 카드로 획득·강화. 칸 3칸 시작, 연구소 무기 가지 "보조 무기 해금"으로 4·5칸 |
| 기본 무기 | 5종(펄스 연사포, 산탄포, 레일건, 플라스마 대포, 채굴 빔). 펄스 연사포만 기본, 나머지는 광물로 연구해서 해금. 거리·조준·채굴량이 확실히 다르게 |
| 무기 진화 | 무기(최대 단계) + 특정 스킬 보유 → 진화. 예: 유도 미사일 + 고폭 탄두 → 연쇄 폭격. 전시관에 진화 도감 |
| 새 스킬 | 6_skill_expansion.md 후보 중 10개 안팎, 진화에 필요한 것 우선 |
| 판 길이 | 보통 10분 안팎(지금 약 5분). 적 등장·피해 증가 곡선 다시 맞춤 |
| 효과 | 화려하게, 폰 성능 안에서. 내 우주선과 적 탄은 항상 잘 보이게 |
| 첫 단계 | 10분 판 흐름표(시간별 적·무기·진화 시점) + 격납고 무기 고르기 화면 시안 |
| 보스 자리 (11-11) | 4:30쯤 중간 보스, 8:00쯤 최종 보스(구현은 v0.9.0, v0.8.0은 시간 자리만). 최종 보스 처치 → 행성 정복 + 귀환 게이트, 안 돌아가면 위험↑·광물↑ 추가 시간. 보스 전 귀환은 선택. 첫 진화는 최종 보스 직전쯤 |

예전 기록과 달라진 점
- 진화 조건: 예전 "두 개 모두 최대 단계" → 이제 "무기만 최대, 짝 스킬은 가지고 있기만 하면 됨".
- 유도 미사일 진화: 예전 예시(집속 미사일 군단 / 분열 탄심 짝) → "고폭 탄두 짝 → 연쇄 폭격".
- 보조 무기 칸: 예전 "늘리는 것은 나중" → v0.8.0에서 연구소로 5칸까지. 지금 `balance.gd` 연구소 칸 `sub`는 최대 1단계·"곧 추가"라 2단계로 바꿔야 함.
- GAME_SPEC 8장 출시 단계 표의 v0.8.0 줄(채굴 드론)은 오래된 내용. 11장 결정이 우선.

## 2. 기본 무기 5종 (안)

| 무기 | 사거리 | 조준 | 채굴량 | 느낌 | 해금 |
|---|---|---|---|---|---|
| 펄스 연사포 | 중간 | 가장 가까운 적 | 보통(×1) | 지금 무기, 무난 | 기본 |
| 산탄포 | 짧음 | 가까운 적 쪽 부채꼴 여러 발 | 조금 많음(운석 여러 개 동시) | 붙어서 싸움 | 연구 |
| 레일건 | 아주 김(화면 끝) | 가장 가까운 대상 쪽 일렬 관통 (2026-11-12 결정으로 "가장 먼 적"에서 바뀜, 12장) | 보통 | 느린 연사, 빛줄기 자체가 공격 | 연구 |
| 플라스마 대포 | 중간 | 적이 많이 모인 곳 | 적음(폭발로 일부 날아감) | 느리고 넓은 폭발 | 연구 |
| 채굴 빔 | 짧음 | 가장 가까운 운석 우선 | 많음(×1.5 안) | 계속 닿는 빔, 적에게 약함 | 연구 |

- 연구는 연구소 무기 가지에 칸으로 넣는다(가격 임시). 격납고는 해금한 무기 중 하나를 고르는 곳.
- 기본 무기는 판 중 바꾸지 않는다(기존 결정 유지). 기본 무기도 진화 대상으로 할지는 열린 질문(아래 6).

## 3. 보조 무기와 진화 (안, 보조 무기 6종 = 진화 6개)

| 보조 무기 | 짝 스킬 | 진화 |
|---|---|---|
| 유도 미사일 포드 | 고폭 탄두 (기존) | 연쇄 폭격 (확정 예시) |
| 블랙홀 발사기 | 냉각 응결탄 (새) | 정지장 붕괴탄 |
