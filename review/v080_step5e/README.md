# v0.8.0 5e단계: 공명 파쇄 다시 만들기 (2026-11-13, 맥)

사용자 결정(GAME_SPEC.md 11장 "공명 파쇄 다시 만들기", PLAN 24장): 우주선 둘레 큰 파동 → 맞은 곳마다 작아지는 파동이 다시 퍼짐(3세대). 레이더 스윕·균열·진동·결정화 후보와 번개 모양 줄은 모두 뺐다.

웹 빌드(`?fxtest`)를 Playwright headless로 열어 찍었다. Godot 창은 띄우지 않았다.

## 동작 (수치는 `Balance.EVO_RES_*`, 그림은 `Juice.RES_FX`)

- 큰 파동: 채굴 펄스 5단계 주기 2.3초·반경 90·피해 5.3. 작은·중간 운석은 한 번에 부서짐(광물 +1, 끌려옴), 큰 운석·다른 적은 피해 ×2.7(운석이 아닌 적은 기존처럼 ×0.5).
- 작은 파동: 맞은 대상(운석·적 모두)마다 그 자리에서 반경 ×0.5·피해 ×0.6 → 45 / 22.5 / 11.25, 3세대까지.
- 큰 파동 하나에서 같은 대상은 한 번만 맞는다(세대끼리 맞은 목록을 같이 씀). 작은 파동은 큰 파동 하나에 24개까지(`EVO_RES_BUDGET`).
- 모든 파동은 세대와 상관없이 0.4초에 끝까지 퍼진다(`EVO_RES_GROW`): 작은 파동도 눈으로 퍼지는 게 보이게.

## 연출

- 파동 띠: 앞쪽 2픽셀이 밝고(맨 앞은 흰빛) 안쪽으로 옅어지는 띠. 두께 9 / 6 / 4 / 3픽셀, 색 금 → 연한 금 → 흰빛, 퍼질수록 옅어짐(끝에서 밝기 30%). 1픽셀 고리를 여러 겹 쌓아 정수 픽셀로 그림(반경 24 이하는 아틀라스 고리).
- 맞은 대상: 0.14초 금빛 번쩍임(세대 색 원 + 흰 가운데). 큰 파동에 부서진 운석은 흰 번쩍임 + 금빛 파편.
- 대상끼리 잇는 줄·번개·꺾인 선 없음. 그리는 층: 내 탄 층(적 탄 아래).
- 소리: 작은 파동이 생길 때 "띵"(광물 종). 세대마다 4반음 높고 3dB 작게. 한 프레임에 가장 큰 파동 하나만, 겹침 상한 2.
- 지운 것: ?fxtest R 키와 화면 구석 "공명 파쇄 후보 n", 후보 그림 코드(균열·음파 점선·결정 조각·운석 떨림), 운석의 공명 표시 값.

## 검수 (넘기기 전에 하나씩 열어 봄)

- 따라가기: `res.gif` 2 → 5 → 9 → 11 → 13번 프레임에서 큰 금빛 고리 → 맞은 운석 자리마다 연한 금빛 고리 → 더 작은 흰 고리 순서로 번지는 게 보인다. 큰 파동은 굵고 밝아 한눈에 보이고, 3세대(반경 11)는 작지만 흰 고리로 운석 위에 보인다.
- 과충전 방전과 다름: 과충전은 우주선에서 사방으로 뻗는 청록 꺾인 번개, 공명 파쇄는 둥근 금빛 고리가 겹겹이 퍼짐. 줄이 하나도 없어 섞여 보이지 않는다(`compare.png`).
- 첫 촬영에서 고친 것: 작은 파동 띠가 너무 옅어(뒤로 갈수록 제곱으로 옅게) 2세대부터 잘 안 보였고, 맞은 대상 금빛 번쩍임(흐린 원 0.7)이 노란 덩어리로 화면을 덮었다 → 띠를 두껍게 + 앞 2픽셀을 같은 밝기로 + 선형으로 옅게, 번쩍임은 반투명 원 0.35 + 작은 흰 가운데로 줄여 다시 찍음.
- 남은 것: 큰 흰 덩어리·주황 파편·주황 원은 기존 운석·적 맞음/부서짐 연출(모든 무기 공통)이라 손대지 않았다. 반경 11~22 작은 고리는 픽셀 원이라 조금 각져 보인다.
- 폰 가로 화면(844x390) 한 번 확인: 파동이 보이고 "후보" 표시 없음, 촬영 모드 FPS 60·효과 25 이하. 콘솔 오류 0(모든 촬영).
