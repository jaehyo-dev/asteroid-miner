# 기지(메인) 화면 시안

**게임에는 아무것도 적용하지 않았어요.** 고르신 뒤에 만들어요. 자료는 전부 이 폴더에 있어요.

## 1. 지금 기지 화면이 왜 떨어져 보이는지 (`now_*.png`, 측정)

| 구분 | 지금 기지 | 출격 화면 | 판단 |
|---|---|---|---|
| 그림 결 | 건물 한 채에 28~39색, 화면 전체 722색. 자글자글한 표면, 붉은 갈색 바닥 | 화면 전체 95색(같은 팩, 팔레트 고정), 넓은 면과 또렷한 외곽선 | **가장 큰 원인.** 같은 게임 그림으로 안 보여요 |
| 픽셀 격자 (PC) | 2화면 픽셀 | 2화면 픽셀 | **같아요.** 계획서 27번의 "픽셀 크기가 다름"은 측정해 보니 PC에서는 틀렸어요 |
| 픽셀 격자 (폰) | 1280x720을 소수 배율로 그려서 그림 1픽셀이 3.25기기 픽셀 (가로 길이 3과 4가 섞임) | 정수 3기기 픽셀 | **폰에서는 달라요.** 들쭉날쭉해 보여요 |
| UI | 테두리 없는 글자와 단순 상자, 글자 36px(3배 격자) | 카드 프레임 S (둥근 금속 판, 리벳, 빛 띠) | 두 화면의 UI가 다른 게임 같아요 |
| 코드 그림 | 길, 가로등, 작은 드론, 이름표가 코드 도형 | 없음 | QUALITY_BAR "도형 그림 없음"에 어긋나요 |
| 움직임 | 표시등 깜빡임, 작은 드론, 가끔 운석. 우주선은 멈춰 있어요 | 항상 움직임 | 멈춘 그림처럼 보여요 |
| 크기 | 건물이 작고 우주선은 화면의 2%쯤 | 우주선이 주인공 | 무엇을 눌러야 할지 "출격"이 약해요 |

## 2. 시안 3개

모두 Codex 그림을 void32 색, 1배 픽셀 격자(PC 2화면 픽셀, 폰 1 CSS 픽셀)로 정리했고, UI는 카드 프레임 S 부품을 그대로 썼어요. 숫자와 글자는 예시예요. `compare_all.png`에 지금과 시안을 나란히 뒀어요.

| | A 배치 유지 | B 구성 새로 | C 궤도 정거장 |
|---|---|---|---|
| 파일 | `mock_A_*` | `mock_B_*` | `mock_C_*` |
| 화면 | 지금처럼 소행성 위 5채 + 가운데 착륙장 | 왼쪽 건물 목록(카드), 가운데 큰 착륙장, 오른쪽 아래 큰 출격 | 위에서 본 정거장, 건물이 고리 둘레의 모듈 |
| 장점 | 익숙하고 작업량이 가장 적어요. 누르는 자리와 코드 대부분을 그대로 써요 | 정보(강화 단계 등)가 잘 보이고 폰에서 누르기 쉬워요. 출격이 가장 뚜렷해요 | 출격 화면과 시점이 같아 가장 하나의 게임 같아요. 팩 결과 가장 비슷해요 |
| 약점 | 건물이 여전히 작고, 폰 이름표가 넓어요 | "기지를 둘러보는" 맛이 줄어요. 화면 코드를 다시 짜야 해요 | **ART_BIBLE의 "기지 = 3/4 조감"과 달라서** 고르시면 문서도 바꿔요. 소행성에서 채굴하는 설정과 멀어져요 |
| 작업량 (감) | 작음 | 중간 | 중간~큼 (드론 공장 등 앞으로 만들 건물도 모듈로) |

**추천: A.** 격자·색·UI를 맞추는 것만으로 차이가 가장 많이 줄어요. 지금 v0.7.0의 목표가 품질 맞추기이고 다음 무기 업데이트가 격납고 화면을 건드리니, 구성 개편은 그때 B를 다시 봐도 돼요. 눈으로 고르면 C가 더 멋있을 수 있어요.

## 3. 대기 중 움직임 (`idle_motion_A.gif`)

GIF에 넣은 것: 건물 불빛 깜빡임, 우주선 대기 엔진 불꽃, 별 시차, 작은 운반 드론 왕복. 어느 시안에든 넣을 수 있어요. 시안 합성이라 실제 게임 속도와는 달라요.

## 4. 시안에서 벗어난 점과 구현 때 할 일

- 폰은 기지도 출격처럼 정수 배율로 바꿔야 해요 (`App.fit_screen`의 기지 모드). 시안의 폰 그림은 그 상태를 가정했어요. **바로 고쳐도 되는 부분이지만 시안 범위라 건드리지 않았어요.**
- 시안의 바닥은 어둡게 눌렀고 길이 없어요. 구현 때 길은 Codex 그림으로 넣어요.
- 폰 이름표는 24px, 위쪽 바 글자 24px예요. 실제 크기는 PNG를 폰 가로 화면에 꽉 채우면 비슷해요.
- 금속 알약 양끝 장식이 넓어서 글자 양옆에 약 31px씩 들어가요. 짧은 이름표용으로 작은 판 그림을 새로 만들면 더 깔끔해요.
- 팩 색 검사는 정리 도구가 void32로 바꿔서 보장되지만, 팩 그림 옆에 놓은 비교는 착륙장 위 우주선 정도예요.
