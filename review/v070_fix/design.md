# 건물 창 새 시안 (게임에 적용 안 함)

게임 코드는 바꾸지 않았어요. `make_mockups.py`가 Codex 그림 6장, 지금 게임의 그림과 기지 캡처, 게임 로직에서 뽑은 실제 수치(`data.json`)로 그린 **그림 시안**이에요. 게임을 실행해 찍은 화면은 아니에요. 표본 상태는 보유 광물 780, 강화 단계 공격력 3, 체력 5, 이동 속도 1, 비상 보험 1, 나머지 0이에요.

## 공통 틀

- 틀: 카드 프레임 S 계열 9칸 금속 틀. 모서리는 그대로, 변만 늘어나요. PC 2배, 폰 1배(카드와 같은 규칙).
- 머리줄: 건물 아이콘, 이름, 보유 광물, 닫기. 폰에서 닫기는 44px 이상.
- 버튼: 하나로 통일. 켜짐(청록 + 어두운 글자), 눌림(내려앉고 어두워짐), 꺼짐(회색).
- 글자: 회색 대신 크림 본문, 청록 제목, 금색 값, 가지 색. 회색은 보조 글에만.
- 위쪽 띠: **창이 열릴 때 위로 들어가요.** 머리줄이 같은 정보를 보여 주니, 띠 아래에 창을 두면 보유 광물이 두 번 보이고 폰에서 38px를 잃어요. 띠를 그대로 두길 원하면 창을 그만큼 낮추면 돼요(내용은 끌어서 봄).
- 전환: 열기 0.18초(아래에서 밀려 들어와 감속), 닫기 0.14초(가속해서 나감). 창이 멈추는 때가 창 소리 A·B·C의 "턱"(약 0.2초)과 맞아요. GIF에는 소리가 없어요.
- 귀환 전환 제안: 위아래 충격 셔터가 닫혀 "쿵"(약한 흔들림) → 기지로 열림. 금속과 금색 위험 띠로 같은 톤이에요.

### 건물이 늘어도 꽂으면 되는 구조 (제안)

`BaseWindow`가 틀, 머리줄, 전환, 닫기, 위쪽 띠를 맡고, 건물은 `{id: 내용 만드는 함수}` 표에 한 줄과 내용 Control만 더해요. 긴 이름 "진화 도감 실험실", "보조 무기 연구소"가 머리줄에 들어가는 것은 스크립트가 확인해요.

## 연구소

- 가지 3개. 무기: 공격력 → 보조 무기 해금 자리(v0.8.0 제안) → 제안 → 제안. 선체: 체력 → 비상 보험 → 제안 → 제안. 채굴: 이동 속도 → 화물칸 → 자석 범위 → 제안 → 제안.
- 상태: 찍음(가지 색 + 관이 빛남), 살 수 있음(은은하게 깜빡), 광물 부족(열렸지만 안 깜빡), 잠김(어두운 실루엣), 제안(빈 자리 + 자물쇠, 수치 없음).
- 잠금 규칙: 앞 칸을 1단계 이상 찍어야 열려요. **예전 저장에서 앞 칸 없이 올린 칸은 잠그지 않아요.** 저장 키, 수치, 가격, 5단계는 그대로예요.

**내 추천: A.** 위로 쌓여 찍는 순서가 바로 읽히고, 폰에서도 진짜 칸이 끌지 않고 다 보여요. B는 더 눈에 띄지만 PC에서도 칸 절반이 화면 밖이라 끌어야 보여요.

## 나머지 건물

- 격납고: 정비 베이 가운데 큰 우주선, 좌우에 능력치 7개(가지와 같은 색). 아래 전투기 칸 4개(잠긴 칸은 실루엣과 "해금 조건 ???"), 기본 무기 자리(v0.8.0 제안).
- 광물 창고: 보여 주는 정보는 지금과 같아요(총가치, 등급별 개수). 탱크는 로그 눈금이고 등급별 1,000개면 가득이에요(3개에도 바닥이 보임).
- 전시관: 진열장 12칸, 못 찾은 것은 불 꺼진 진열장에 검은 실루엣과 ?. 위에 발견 수와 진행 막대, 진화 도감 탭 자리. 설명 12줄(스크립트 `SHORT`)은 이번에 새로 쓴 글이에요. 설계서 내용에 맞췄지만 문구는 고쳐도 돼요.
- 드론 공장: 파란 설계도 + "건설 예정". 지금 토스트 안내 대신 창이 열리게 돼요.

## 정해 주실 것

1. 창 소리 A~D, 카드 등장 A~D
2. 연구소 A 또는 B
3. 이름 (`names.md`)
4. 채굴 가지 순서: 요청대로 이동 속도(150) → 화물칸(120) → 자석(100)으로 했어요. 그러면 지금 가장 싼 자석에 270을 먼저 써야 해서 **초반 성장이 조금 느려져요.** 싼 순서(자석 → 화물칸 → 이동 속도)도 가능해요.

## 확인한 것과 못 한 것

- 확인: PC 2배 격자 일치(2x2 칸 전부 같은 색), 글자 넘침 검사 0건, 창이 화면 안, 잠금 규칙·탱크 눈금 assert. 새 그림은 void32 + 어두운 바탕 `#14111c`(카드와 같음)이고, 창 안 99% 이상이 이 색이에요. 나머지는 선택 빛의 반투명과 원래 있던 게임 그림(우주선, 운석, 적)의 색이에요.
- 못 한 것: 게임에서 실제로 돌리지 않아 터치, 끌기, 성능, 실제 폰 글자 크기는 확인 못 했어요. 폰 작은 글자는 12px예요.
- 그림은 시안이라 `tools/pixelate.py` 대신 카드 프레임 시안과 같은 `make_frames.pixelize`로 줄였어요. 적용할 때 부품 크기를 확정하고 정리 도구로 다시 뽑아요.
