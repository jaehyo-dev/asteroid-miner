# 소리 후보 (게임에 넣지 않음)

**저는 귀로 듣지 못해요.** 파형과 숫자(`measure.md`, `wave.png`)로만 확인했어요. 고르는 것은 들어 보고 결정해 주세요. e3(`assets/sfx/game/card_pick.wav`)는 바꾸지 않았고, 스크립트가 md5로 확인해요.

## 1) 창 열기·닫기

| 짝 | 느낌 | 재료 |
|---|---|---|
| A | 에어록 "치익-턱". 닫기는 "턱-칙" | 추진기 잡음(공기), 칼 내려치는 소리(걸쇠), 금속판 |
| B | 금속 패널이 옆으로 "스르륵-탁" | 칼 긁는 소리를 낮춤, 금속 충돌, 금속판 |
| C | 유압 해치 "푸쉬-쿵". 가장 낮고 무거움 | 낮은 추진기 잡음, 무거운 금속판 |
| D | 단말기 "삑-딸깍". 닫기는 "딸깍-뽁" | 부드러운 합성 두 음(2kHz 아래), 금속 스위치 |

파일: `door_X_open.ogg`, `door_X_close.ogg`, 열기-닫기를 2번 이어 놓은 `door_X_pair.ogg`.

공통으로 맞춘 것: 열기 0.40초 이하, 닫기 0.30초 이하이고 열기보다 짧고 낮게(무게중심 비교). 9kHz 위 1% 미만. A·B·C는 "턱" 소리가 약 0.2초에 있어 0.18초 뒤 창이 멈추는 움직임과 맞아요. 재료 파일은 카드 후보·지금 카드 소리와 하나도 겹치지 않아요(같은 팩의 다른 파일).

**내 추천: A.** 정거장 느낌이 가장 분명하고, "부웅" 뜨는 느낌과 가장 멀어요(들어 보기 전 의견). D는 자주 열어도 덜 피곤할 수 있어요. 다만 합성 음이라 다른 후보와 질감이 달라요.

## 2) 카드 등장

전부 실제 녹음(CC0)이고 합성음은 없어요. 얇은 금속 녹음은 e3 원본에 건 것과 같은 음색 처리를 해서 질감을 맞췄어요.

| 후보 | 느낌 | 재료 |
|---|---|---|
| A | 금속 위로 "스윽-탁" | Kenney 칼 뽑는 소리, 카드 미끄러짐, 금속 충돌 |
| B | 탄창 끼우는 "착" | **e3와 같은 권총 녹음**의 탄창 구간(0.585~0.81초) |
| C | 금속판 펼침 "틱-틱-착" | 금속 충돌 3개를 차례로, 금속판 |
| D | 딜러 돌리기 + 금속 울림 | 실제 카드 튕김, 금속 충돌의 꼬리 |

파일(X = A~D):
- `card_X_normal.ogg`(노멀·레어), `card_X_epic.ogg`, `card_X_unique.ogg`, `card_X_legend.ogg`: 하나씩
- `card_X_3cards.ogg`: 노멀, 레어, 에픽 3장을 게임 시간표대로
- `card_X_3cards_to_e3.ogg`: 위 3장 → 0.9초 → e3 선택 (**이걸 먼저 들어 보세요**)
- `card_X_high_to_e3.ogg`: 에픽, 유니크, 레전드리 → e3

리듬: 게임의 카드 간격 0.28초에 맞췄고, 앞면이 보이는 순간(카드 시작 0.16초 뒤)에 소리의 가장 센 지점이 오게 놓았어요. 노멀·레어 소리는 모두 -30dB 기준 0.28초 안에 끝나 다음 카드와 안 뭉쳐요(자동 확인). 다시 뽑기는 간격이 0.08초라 겹쳐요. 적용할 때 들어 봐야 해요.

등급: 에픽·유니크는 쇠종 녹음의 은은한 울림을 살짝 얹고, 레전드리는 쇠종 2개로 더 크고 길어요. 예전 `card_swell`, `card_gather`도 합성이라 같은 쇠 녹음을 거꾸로 튼 모임 소리로 바꿔 넣었어요.

**바뀌는 점:** 요청대로 에픽부터만 울림을 얹어서, 레어는 예전의 반짝임이 사라지고 소리로 노멀과 같아져요. 레어는 빛으로만 구분돼요.

**내 추천: B.** 같은 녹음이라 e3와 질감이 가장 같아요. 다만 "착" 다음 e3의 "철컥"이 같은 총 소리로 이어져 무겁게 들릴 수 있고, 등장이 3번 반복되면 조금 공격적일 수 있어요. 카드를 내놓는 느낌은 A가 더 가까워요.
