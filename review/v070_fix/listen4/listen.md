# UI 버튼 소리 후보 (게임에서 골라 보는 시험용)

**저는 귀로 듣지 못해요.** 파형과 숫자(`measure.md`)로만 확인했어요. 파일로는 `click_N_demo.ogg`(천천히 3번 → 연타 6번 → 강화 1번)를 먼저 들으면 돼요.

| 후보 | 소리 | 재료 |
|---|---|---|
| 1 부드러운 톡 | 아래로 살짝 떨어지는 둥근 음 | 합성 |
| 2 작은 공기 톡 | 창 소리의 슉을 아주 짧게 + 작은 낮은 음 | 합성 |
| 3 낮은 딸깍 | 창 소리 딸깍과 같은 재료를 낮춤 + 몸통 음 | 합성 + Kenney RPG Audio `metalClick` |
| 4 짧은 홀로그램 톡 | 살짝 올라가는 짧은 음 + 작은 반짝 | 합성 |

- 길이 0.08초 안쪽, 음높이 흔들림 ±5%, 크기는 창 소리보다 2dB 작음(가장 큰 50ms 구간, 길이가 짧아 전체 에너지는 더 작음).
- `click_N_up`: 강화 성공용. 같은 소리를 22% 높고 1dB 크게. 지금 강화 소리는 광물 "띠링"(`pickup_2`)이에요.

## 게임에서 비교하기
`bash tools/serve_web.sh`로 띄운 뒤 주소 끝에 `?clicktest`. 기지 오른쪽 아래 작은 버튼을 누를 때마다 1 → 2 → 3 → 4 → 지금 소리로 바뀌고, 그 소리가 나며 이름이 잠깐 떠요. 그다음 연구소에서 탭·칸·강화를 눌러 보세요.
