# 연구소 강화 소리 후보 (게임에서 골라 보는 시험용)

**저는 귀로 듣지 못해요.** 파형과 숫자(`measure.md`)로만 맞췄어요.

| 파일 | 소리 | 재료 |
|---|---|---|
| `upgrade_1` 탄창 착-칵 | 탄창이 끝까지 들어가 걸리는 두 번 소리 | zer0_sol 권총 녹음 0.64~0.80초 |
| `upgrade_2` 슬라이드 놓음 컥 | e3의 끝 "컥"만, 10% 높여 가볍게 | 같은 녹음 1.175~1.34초 |
| `upgrade_3` 걸쇠 틱-착 | 탄창 멈치 "틱" → 탄창 첫 "착" | 같은 녹음 0.09~0.15초 + 0.59~0.65초 |
| `max_tail_1` 묵직한 쇠종 | 낮게 내린 종 하나가 길게 (1.8초) | Kenney Impact `impactBell_heavy_000` |
| `max_tail_2` 레전드리 두 종 | 카드 레전드리 울림과 같은 두 종, 좌우로 | `impactBell_heavy_000·001` |
| `max_tail_3` 금속판 쿵 + 울림 | 무거운 판 "쿵" + 짧은 종 | `impactPlate_medium_000` + `impactBell_heavy_000` |
| `deny` 광물 부족 툭 | 버튼 소리 1번을 낮고 둔하게 | 합성 |

- 강화: e3(0.49초)보다 짧게(0.16~0.20초), 2dB 작게. e3와 같은 음색 처리(몸통 올림, 고음 깎음). 음 높이 ±3% 흔들림.
- 만렙: 강화 소리를 2dB 크게 + 칸이 하얗게 번쩍이는 순간(빛이 칸에 닿을 때)에 꼬리를 얹음. 꼬리는 e3보다 1dB 크게.
- 광물 부족: 꺼진 강화·해금 버튼을 누르면 남. 버튼 소리보다 1dB 작고 낮게.
- 갈림길 해금 = 강화 소리, 갈림길 바꾸기 = 버튼 소리.

## 파일로 듣기
- `upgrade_N_rapid.ogg`: 강화 연타 6번
- `max_N_demo.ogg`: 강화 2번 → 만렙(강화 1·2·3 + 꼬리 N)
- `deny.ogg`

## 게임에서 비교하기
`bash tools/serve_web.sh`로 띄운 뒤 주소 끝에 `?upgradetest`. 기지 오른쪽 아래 버튼 3개:
- **강화 소리**: 누를 때마다 1 → 2 → 3 → 1 (처음은 1), 그 소리가 나고 이름이 뜸
- **만렙 소리**: 같은 방식으로 꼬리 1 → 3
- **광물 +5만**: 광물을 넣어 줌 (이 주소의 저장에만 남음, 게임 주소 저장과는 따로)
