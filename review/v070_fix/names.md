# 이름 후보 표

효과 숫자, 저장 키(`damage`, `max_hp`, `speed`, `cargo`, `insurance`, `magnet`)는 그대로예요. 시안 그림에는 **1번 후보**를 넣었어요. 다른 게임 이름에서 가져오지 않았고, 레벨업 카드 이름과 똑같은 것도 없어요(비슷한 것은 "겹침"에 적었어요).
