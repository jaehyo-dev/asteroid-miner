# 건물 창 시안 2차 (게임에 적용 안 함)

게임 코드는 바꾸지 않았어요. `make_mockups2.py`가 1차 틀·부품과 Codex 그림 3장으로 그린 **그림 시안**이에요(회전 시험만 실제 Godot). 표본 상태는 1차와 같아요(광물 780, 공격력 3, 체력 5, 이동 속도 1, 비상 보험 1).

**주황색 "제안"이 붙은 이름·효과·가격은 전부 예시예요.** 기존 강화 6개의 수치·가격·5단계·저장 키는 그대로이고, 스크립트가 `data.json`과 대조해요.

파일 이름 뒤에 `_pc_1280x720.png`, `_phone_844x390.png`가 붙어요. PC 2배, 폰 1배로 1차와 같아요.

### 1차에서 고친 것

- "채굴 계통" 글자가 칸을 가림: 가지 이름을 맨 아래 줄로 옮겼어요. 맨 위 칸까지 PC·폰 모두 처음 화면에 들어와요.
- "선체 계통"과 "1/5단계" 겹침: 줄 간격을 고쳤어요.
- 비어 보이던 오른쪽 칸: 코어 설명, 가지별 진행, 찍은 단계 합계를 넣었어요.
- 최대 단계 캡처를 추가했어요. 버튼 글자는 "최대"예요.

### 5가지 읽히게 하기

처음에는 코어와 기존 3가지(무기, 선체, 채굴)가 보이고, 새 2가지는 바깥에 있어요. 끌어서 보고, 화면 밖 가지는 가장자리 "◀ 전자", "탐사 ▶"로 알려 줘요. 폰은 바깥 칸이 조금 잘려 보여서 더 있다는 걸 알 수 있어요.

### 갈림길 (모두 제안, 고르는 값 예시 500)

| 가지 | A | B |
|---|---|---|
| 무기 | 연사형: 공격 속도 +15%, 공격력 -5% | 한 방형: 공격력 +25%, 공격 속도 -15% |
| 선체 | 중장갑: 체력 +30, 이동 속도 -5% | 회피형: 피격 뒤 무적 +0.3초 |
| 채굴 | 넓게 끌기: 자석 범위 +40% | 빨리 나르기: 끌려오는 속도 +60% |
| 전자 | 고급 회로: 에픽 이상 확률 +3% | 실드 충전: 60초마다 실드 1번 충전 |
| 탐사 | 심부 스캔: 영웅·전설 확률 +2% | 광역 스캔: 레이더 범위 +30% |

- 표현: 고른 쪽은 가지 색으로 빛나고 관이 이어져요. 안 고른 쪽은 셔터가 내려오고 자물쇠가 걸려요(GIF에 닫히는 모습).
- 고르는 방법: 잘못 누르지 않게 오른쪽 카드를 눌러 고른 뒤 버튼으로 확정해요.

### 선택 바꾸는 방법 (정할 것)

| 방법 | 장점 | 단점 |
|---|---|---|
| **광물을 내고 바꾸기, 언제든 (추천)** 예시 150, 바꿀 때마다 +50 | 실험해도 부담이 적고 광물을 쓸 곳이 생김 | 값을 맞춰야 함 |

| 못 바꿈 | 선택이 무거워짐 | 처음 하는 사람이 후회할 수 있음 |

### 회전 방법 비교 (실제로 만들어 돌림, `spin3d/`)

| | (a) 실시간 복셀 + SubViewport | (b) 미리 만든 프레임 |
|---|---|---|
| 만드는 법 | 스프라이트 칸마다 두께를 줘서 모형 (402칸, 삼각형 약 2,800개). 64x56에 찍고 nearest로 3배 | (a)를 찍어 40장 시트로 굽고 1픽셀 검은 윤곽 추가 |
| 움직임 | 끊김 없이 매끄러움 | 0.15초마다 한 칸, 또각또각 |
| 그림 | 윤곽선 없음, 각도에 따라 칸이 조금 일렁임 | 윤곽이 또렷해 게임 그림과 비슷함 |
| 추가 용량 | 코드만 | 전투기마다 PNG 약 20KB |
| 위험 | 게임에 3D를 처음 넣음 | 거의 없음 |
| 새 전투기 | 그림만 있으면 자동 | `bake.py` 한 번 |

시험 결과: (a)를 웹으로 내보내 헤드리스 Chromium(소프트웨어 렌더링)에서 돌렸더니 **약 60fps, 콘솔 오류 0건**이었어요. 진짜 폰에서는 재지 못했어요. 면 방향별 밝기를 칸 색에 미리 구워서 빛 계산이 없고, 게임 스레드 없음·Compatibility 설정과 같아요.

**내 추천: (b) + 홀로그램 받침.** 윤곽이 있어 다른 화면과 어울리고 3D 위험이 없어요. 끊김이 거슬리면 60장으로 늘려도 약 30KB예요. 다만 움직임은 눈으로 봐야 알 수 있으니 비교 GIF로 정해 주세요.
