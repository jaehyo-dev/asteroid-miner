# 1) 레벨업 카드 스킬 전수 점검 (v0.7.0, 브랜치 v0.7.0-polish 8a3ec31)

근거: `scripts/balance.gd`(수치·문구), `scripts/logic/upgrades.gd` `add_bonus`(쌓이는 방식), `scripts/logic/run_sim.gd` `apply_upgrades`(실제 적용).
실제 값은 시뮬레이터에 카드를 직접 적용해서 확인했다 (`stack_check` 결과는 맨 아래).

| 이름 | 툴팁 (E / U) | 실제 코드 효과 | 쌓이는 방식 | 최대 | 판정 |
|---|---|---|---|---|---|
| 텅스텐 관통탄 | 1개 / 2개 더 관통 | 관통 수 +1 / +2, 상한 4 | 더해짐, 상한 | 3번 | ❌ U·U면 이미 4(상한)인데 3번째 카드가 계속 나옴 → 찍어도 0 |
| 반사 코팅 탄 | 1번 / 2번 튕김 (피해 70%) | 튕김 +1 / +2, 상한 3 | 더해짐, 상한 | 2번 | ⚠️ U·U = 4가 아니라 3 (1번 손해, 문구에 상한 없음) |
| 고폭 탄두 | 부술 때 반경 24 / 36, 피해 50 / 75% | 처음: 그 등급 값. 다음부터: 반경 = 큰 쪽 + 6, 비율 = 큰 쪽 | 갱신 + 조금 더함 | 3번 | ⚠️ 두 번째 카드도 "반경 24"라고 쓰여 있지만 실제는 +6 (24→30→36). E 다음 E는 비율이 그대로 50% |
| 표적 분석 AI | 치명타 15% / 25% (2배) | 확률 더함, 상한 50% | 더해짐, 상한 | 3번 | ❌ U·U = 50%(상한)인데 3번째 카드가 계속 나옴 |
| 편향 실드 발생기 | 20초 / 12초마다 1번 막음 | 처음: 그 등급 간격. 다음부터: 간격 = min(지금, 카드 값) − 3초, 최소 8초 | 갱신 + 줄임 | 3번 | ⚠️ **사용자 발견.** 카드에는 늘 "20초/12초마다"라고 쓰여 있어 새 실드가 하나 더 생기는 것처럼 보임. 실제로는 실드 하나의 간격만 준다: E→E 17초, U→E 9초(카드는 "20초"). 게다가 연구소 "편향 실드"(판마다 횟수)와 "실드 충전"(60초마다 1번)은 **다른 장치**인데 이름이 같고, 연구소 쪽 남은 횟수는 화면에 안 보임 |

## 고치는 안 (다음 단계에서, 게임 코드는 아직 안 바꿈)

1. **상한에 닿은 카드는 뽑지 않기** (관통·치명타·드론·채굴, 반사도 같이): `Upgrades.available_in`이 고른 횟수뿐 아니라 "지금 값 ≥ 상한"도 보게. 낭비 카드가 없어짐. 테스트: 상한 도달 뒤 그 카드가 안 나오는지.
2. **카드 문구를 "지금 → 다음"으로**: 이미 가진 효과 카드는 `드론 2기 → 3기`, `실드 12초 → 9초마다`, `폭발 반경 24 → 30`처럼. 처음 찍는 카드는 지금 문구 그대로. 유니크 문구는 "+2기"로(현재 "2기").
3. **드론 상한**: 상한 3은 그대로 두고 문구만 고치는 안(A, 추천) / 상한을 4로 올려 U·U = 4기가 되게 하는 안(B, 화면 탄 수와 폰 성능을 다시 재야 함).
4. **실드 하나로 보이게**: 카드 실드는 "실드 발생기"로 이름을 다르게(예: "편향 실드 충전기"), 연구소 실드의 남은 횟수는 HUD에 작은 칸으로 표시. 장치는 지금처럼 둘이지만 화면에서 구분됨. (하나로 합치는 안은 저장·연구소 문구가 같이 바뀌어 v0.8.0 때 권장)
5. **고밀도 탄두 문구**를 %로 (+0.75 → +75%). 계산은 그대로.
6. **연쇄 반사 매트릭스 문구**에 "반사 탄 튕김 피해도 80%로" 추가.
7. **연구소 과부하 탄두** 이름을 겹치지 않게(예: "5연발 증폭탄"). 저장 키는 그대로.

## 실행 확인 (stack_check, 작업 사본에서 시뮬레이터에 카드 직접 적용)

```
드론 U → 2기 / 드론 U,U → 3기 (그리고 드론 카드 계속 나옴) / 드론 E,E,E → 3기
실드 E → 20초 / U → 12초 / U,E → 9초 / E,E → 17초 / U,U,U → 8초
관통 U,U → 4 (관통 카드 계속 나옴) / 튕김 U,U → 3 / 치명 U,U → 50% (계속 나옴) / 채굴 U,U → 100% (계속 나옴)
폭발 E,E,E → 반경 36, 비율 50% / 폭발 U,E → 반경 42, 비율 75%
다중 U×4 → 9발 피해 1.0 / 다중 E×4 → 5발 피해 1.8
연쇄 매트릭스 + 반사 U → 튕김 5
```
