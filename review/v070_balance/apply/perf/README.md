## 판단
- 두 번 다 측정 도중 다른 게임 세션의 브라우저 측정이 함께 돌아 부하가 3을 넘었다(2차는 시작 1.9, early PC 이후 4~10). 절대값은 믿기 어렵고, 번갈아 잰 직전/지금 차이만 참고.
- 1차: 후반 장면에서 지금 버전의 스크립트 시간이 +1.0ms(PC), +2.5ms(CPU 4배)로 일관되게 늘었다 → 매 프레임 합치기 검사가 원인으로 보고 0.2초마다 검사로 바꿈.
- 2차: 후반 PC는 직전보다 스크립트가 오히려 짧고 FPS도 비슷하거나 높음. CPU 4배는 스크립트 +2.9ms로 남았지만 FPS·p95는 더 좋음 → 부하 흔들림 안. 폰·초반은 차이 없음.
- 사용자가 본 "PC 15.2fps, 폰 8.4fps"는 밸런스 봇 6개가 CPU를 다 쓰던 중 + 레벨업 카드 화면에 멈춘 상태에서 잰 값이라 무효. 초반 PC 57fps는 v0.7.0 마무리 때(60)와 비슷하다.
- 남은 확인: 부하 3 이하가 유지될 때 한 번 더(특히 후반 CPU 4배). 폰 23fps는 직전 버전도 같아 이번 변경 때문이 아님(마무리 때 30.1과의 차이는 측정 장면·부하 차이로 보임).
