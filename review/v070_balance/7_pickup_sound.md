# 7) 광물 줍기 소리 (후반에 겹쳐 시끄러움)

## 지금 규칙 (`scripts/run.gd` 줍기 부분, `scripts/sfx.gd`, `scripts/logic/pickup_combo.gd`)
- 등급마다 한 프레임에 한 번만 냄. 등급별 재생기 2개 → 4등급이면 **동시에 최대 8개**.
- 1초 안에 또 주우면 1반음씩 올라가 **최대 12반음(한 옥타브)**. 후반에는 거의 늘 줍기 때문에 **85%가 가장 높은 음**으로 남. 짧고 날카로운 소리가 이어짐.
- 줍는 수가 많아도 한 번의 음량은 그대로(운석 깨짐 소리에는 몰림 줄임이 있지만 줍기에는 없음).

## 후반 측정 (4~5분, collector 봇, 기지 6칸 최대 + 좋은 카드, 시드 10판, 60fps 기준)
| 항목 | 지금 | 시안 |
|---|---|---|
| 줍는 개수 | 평균 4.4개/초, 1초 최대 35개 | 같음 |
| 실제 재생 (평균) | 3.2번/초 | 2.5번/초 |
| 실제 재생 (가장 바쁜 10%의 초) | **12.5번/초** | **8.1번/초** |
| 동시 재생 최대 | 6개 | **3개** |
| 가장 바쁜 초의 소리 에너지 합 | −10.4 dB | **−14.6 dB** (−4.2) |
| 가장 높은 음에 머무는 비율 | 85% (12반음) | 78% (5반음) |

(측정 도구 `tools/pickup_measure.gd.txt`: 재생기 수·소리 길이·음 높이에 따른 길이 변화까지 반영)

## 고치는 안 (작업 사본에서 시안으로 만들어 녹음함, 게임 코드는 안 바꿈)
1. **묶기**: 0.05초 안에 주운 광물은 소리 한 번. 그 묶음에서 **가장 높은 등급 소리**를 냄(희귀 이상이 일반에 묻히지 않음). 묶음 안에서 더 높은 등급이 들어오면 그건 따로 냄.
2. **많을수록 한 번을 작게**: 최근 1초 재생 수가 3번을 넘으면 한 번의 음량 = −10·log10(횟수/3) dB. 1초에 12번이면 −6dB → 전체 크기가 3번/초일 때와 비슷하게 유지됨. **전설**은 −3dB까지만 줄여 항상 들리게.
3. **콤보 음**: 묶음마다 1반음씩, **최대 5반음**(지금 12), **0.6초** 끊기면 처음 음으로(지금 1초). 귀를 찌르는 높은 음역(3kHz 이상)이 녹음에서 −4.4dB.
4. **동시 재생 전체 3개**(지금 등급별 2개 × 4).
- 수치는 `juice.gd` 한 곳에 (`PICKUP_GROUP_TIME`, `PICKUP_RATE_REF`, `PICKUP_COMBO_MAX_SEMITONES` 5, `PICKUP_COMBO_WINDOW` 0.6, `PICKUP_MAX_VOICES` 3, `PICKUP_LEGEND_FLOOR_DB`).
- 로직은 `scripts/logic/`에 두고 시간(now)을 받아 테스트: 0.05초 안 묶기, 높은 등급 우선, 1초 12번일 때 −6dB, 0.6초 끊기면 0반음, 5반음 상한.
- 시안 코드: `tools/pickup_sound.gd.txt` (작업 사본 전체 변경은 `tools/worktree_mock.diff`).

## 녹음 비교 (같은 시드·같은 판, 4분부터 40초 중 마지막 30초, 배경음 끔)
| 파일 | 내용 | 통합 크기 | 순간(0.4초) 최대 | 3kHz 이상 |
|---|---|---|---|---|
| `pickup_sound/late30_pickup_only_old.ogg` | 지금, 줍기 소리만 | −22.0 LUFS | −15.6 | −32.5 dB |
| `pickup_sound/late30_pickup_only_new.ogg` | 시안, 줍기 소리만 | −22.2 LUFS | −17.7 | −36.9 dB |
| `pickup_sound/late30_all_old.ogg` | 지금, 효과음 전부 | −16.8 LUFS | | |
| `pickup_sound/late30_all_new.ogg` | 시안, 효과음 전부 | −17.0 LUFS | | |

- 통합 크기(평균)는 거의 같고, 줄어든 것은 **몰릴 때의 순간 크기와 날카로움**. 지금 소리는 한 옥타브 올라 짧아져서 평균 크기에는 덜 잡히지만 귀에는 더 거슬림.
- 녹음은 Godot 영상 기록(`--write-movie`)의 소리를 ffmpeg로 잘라 만든 것. **나는 귀로 듣지 못함** → 사용자가 두 파일을 번갈아 들어 판단해야 함.
- 녹음 판은 출격 직후 시각을 4분으로 옮기고 후반 강화를 미리 넣은 시험 판(죽지 않게 체력 큼). 실제 4분 판과 적 수는 같고 운석 체력은 계단만큼 다를 수 있음.
