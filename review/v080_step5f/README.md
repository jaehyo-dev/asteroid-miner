## 연출 (수치 `Juice.RES_FX`, `RES_GLOW_TIME`, `RES_SHAKE*`)

- 큰 파동: 7픽셀 띠(앞 흰빛 금 → 금 → 주황, 뒤로 옅게) + 반짝이 14개(밝을 때 + 모양) + 띠가 지나간 자리에 0.3초 남는 금가루 64개. 나갈 때 우주선 둘레 0.1초 금빛 섬광 + 빛줄기 7개(우주선은 그 위에 그려짐).
- 작은 파동: 맞은 자리에 0.12초 별 번쩍임(빛줄기 6/5/4개) → 파동. 1세대 금 4px · 2세대 연한 금 3px · 3세대 흰빛+청록 2px, 앞 가장자리 밝기는 세대마다 같음. 반짝이 6/4/3개.
- 다 퍼지면 띠는 바로 빼고 반짝이만 조금 더 퍼지며 0.12초에 사라짐(옅어지는 띠·1px만 남는 고리는 회색 선처럼 보여서).
- 맞은 대상: 흰 실루엣 대신 0.1초 금빛 섞기(50%). 부서지면 금빛 결정 조각 8 + 금가루 10, 살아남은 큰 운석·적은 금빛 금 무늬 0.45초.
- 짝 스킬 광맥 공명기 충격파도 흰 실루엣 대신 같은 금빛 달아오름(공명 파쇄 장면의 흰 덩어리 원인 중 하나였음).
- 연쇄가 3세대까지 이어지면 큰 파동마다 한 번 화면 흔들림 1픽셀 0.1초. 화면 전체 번쩍임 없음.
- 그리는 층은 그대로 내 탄 층(적 탄·우주선 아래). 파동 그림 상한 50개, 맞은 자리 24개.

## 촬영 중 고친 것 (4번 다시 찍음)

1. 잔광을 옅은 금빛 띠로 깔았더니 어두운 바탕에서 올리브·갈색 원판/고리로 보임 → 띠를 빼고 금가루로.
2. 다 퍼진 파동이 옅어지며 사라질 때 1px 흰·금 선이 회색 고리처럼 남음 → 띠는 바로 빼고 반짝이만 흩어짐.
3. 금빛 달아오름 60%가 노란 덩어리처럼 보임 → 50%, 주황 쪽 금.
4. 2·3세대 띠 뒤쪽(낮은 밝기 흰빛)이 회색처럼 보임 → 뒤쪽 색을 금·청록으로.

## 검수 (넘기기 전에 하나씩 열어 봄)

1. 회색 원: 공명 파쇄가 그리는 회색 원 없음. 단, `res.gif` 17~19번 프레임 우주선 둘레 크림색 원판+고리는 레벨업 빛(기존 연출)이다.
2. 흰 덩어리: 공명 파쇄·광맥 공명기는 흰 실루엣을 쓰지 않는다(자동 테스트). 단, `res.gif`에 2~3번(예: 46·56·82번 프레임) 흰 실루엣이 보이는데 기본 무기(펄스 연사포) 탄이 맞을 때의 기존 흰 번쩍임(0.05초, 모든 무기 공통)이다.
3. 채굴 펄스 5단계보다 화려함: 굵은 금빛 띠 + 반짝이 + 섬광 + 겹겹이 번지는 작은 파동(`compare.png`).
4. 3세대: `res_3_gen23.png`에 2세대(연한 금)·3세대(흰빛 작은 고리)가 운석 위에 보인다.
5. 과충전 방전과 다름: 방전은 청록 꺾인 번개, 공명 파쇄는 금빛 고리.
6. 적 탄·우주선: 파동은 적 탄·우주선 아래 층이라 가리지 않음, 큰 파동 섬광도 우주선 아래.
