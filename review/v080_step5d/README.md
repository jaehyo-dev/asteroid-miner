# v0.8.0 5d단계: 진화 카드 소리 확정 + 공명 파쇄 이펙트 후보 3개 (2026-11-13, 맥)

사용자 결정(GAME_SPEC.md 11장 "진화 카드 소리 확정·공명 파쇄 그림 다시 고르기", PLAN 23장): 진화 소리는 등장·고를 때 모두 후보 2, 공명 파쇄는 레이더 스윕 그림을 빼고 이펙트 후보 3개 중 인게임에서 고름.

웹 빌드(`?fxtest`)를 Playwright headless로 열어 찍었다. Godot 창은 띄우지 않았다. (설치된 Chrome을 Playwright 임시 프로필로 headless 실행)

## 후보 (기능은 5c 그대로, 그림만 다름)

공통: 레이더 부채꼴 스윕 그림 없음(표시 판정은 그대로 0.6초 동안 둘레를 훑음). 연쇄 종소리(음이 올라감) 그대로. 정수 픽셀, 내 탄 층(적 탄 아래). 연쇄 줄·날아가는 조각은 `Juice.SUB_FX_MAX`(16), 터지는 자리는 `Juice.SUB_HIT_MAX`(24) 상한. 원 경계선 없음.

| 후보 | 표시가 붙을 때 | 표시된 운석 | 연쇄가 보이는 방식 | 터질 때 |
|---|---|---|---|---|
| 1 균열 | 우주선(또는 터진 운석)에서 번개처럼 꺾인 금빛 균열이 0.06초에 뻗고 잔가지가 갈라짐 | 가운데에서 6갈래 금이 0.1초에 쫙 퍼짐(흰 심 + 금빛 번짐) | 터진 운석에서 다음 운석으로 균열이 뻗음 | 갈라진 금에서 빛줄기 + 운석 파편(2칸) + 금빛 부스러기 |
| 2 진동 | (줄 없음) 바로 떨기 시작 | 좌우로 1→2픽셀 부르르 + 반대쪽 금빛 잔상 + 양옆 떨림 줄, 0.4초에 걸쳐 금빛 → 흰 가운데로 달아오름 | 앞에 터진 운석에서 다음 운석으로 물결치는 음파 점선(밝은 마디가 앞으로 흐름) | 작은 흰 번쩍임 + 금빛 번짐 + 파편 |
| 3 결정화 | 금빛 결정 조각(마름모 + 꼬리)이 0.1초 날아가 박힘 | 금빛 결정 가시 7개가 0.1초에 자람 + 반짝이는 결정 면 | 터진 운석에서 튄 결정 조각이 옆 운석에 박혀 그 운석도 결정화 | 금빛 결정 조각(5c 그대로) |

- 화면 흔들림: 후보 2도 운석만 떨고 화면은 흔들지 않음.
- 그리기 수치는 `Juice.RES_FX`(grow 0.1, fly 0.1, shake 2, heat 0.4, spikes 7, dot_gap 5). 후보 번호는 `SubWeaponFx.res_style`(기본 1), ?fxtest R로 1 → 2 → 3.

## 검수 (넘기기 전에 하나씩 열어 봄)

- 5단계 ↔ 후보: 5단계는 육각 격자 고리가 퍼지고 운석에 금만 감. 후보 1은 우주선에서 사방으로 뻗는 긴 번개 균열, 후보 2는 금빛으로 달아오른 운석 + 떨림 줄 + 점선, 후보 3은 가시 돋친 금빛 결정 운석. 넷 다 한눈에 다르다(`compare_wave.png`).
- 연쇄 따라가기: 1은 균열 선이, 2는 점선이 터진 운석 → 다음 운석으로 이어져 연속 프레임에서 번지는 방향이 보인다. 3은 결정 조각이 날아가는 시간이 0.1초로 짧아 GIF 한 장에는 잘 안 잡히지만, 가시 돋친 운석이 차례로 늘었다 깨지는 게 보인다.
- 다시 찍은 것: 첫 촬영에서 후보 2가 ① 터질 때 흰 원이 커서(반경 ×1.4, 진하기 0.8) 화면을 덮고 ② 주황 → 금빛 달아오름이 보라 운석 위에서 갈색으로 보였고 ③ 1픽셀 점선이 거의 안 보였다 → 흰 원을 ×0.7·0.5·0.15초로 줄이고, 달아오름을 금 → 흰빛으로 진하게, 점을 2픽셀로. 후보 3의 날아가는 조각도 꼬리를 늘림. 후보 2·3만 다시 찍음(같은 순서로 찍었지만 운석 배치는 무작위라 조금 다름).
- 남은 것: 화면의 큰 흰 덩어리·주황 파편은 기존 운석 맞음 번쩍임·부서짐 연출(모든 후보 공통)이다. 후보 3은 둘째 촬영에서 주변에 작은 운석이 적어 가시 운석이 첫 촬영보다 덜 잡혔다.
- 콘솔 오류 0 (모든 촬영).
