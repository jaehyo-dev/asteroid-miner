- 채굴 빔 "큰 흰 덩어리": 버그가 아니라 모든 무기에 있는 **적 맞음 번쩍임**(맞은 대상 그림 전체를 0.05초 하얗게, 모든 그림 위 층)이었음. 빔은 0.3초마다 이걸 켜서 운석이 통째로 하얗게 덮였음 → 빔은 운석 전체 번쩍임을 아예 끄고, 맞은 표시는 빔 끝 빛(운석 아래 층)·불꽃으로만. 자동 테스트로 확인.
- 촬영용 조정: 해파리가 우주선에 부딪히면 화면이 붉게 번쩍여 이펙트를 가려서, 촬영 중에는 닿기 직전(우주선에서 반지름+14픽셀)에 부서지게 함. 게임에는 없음.
- 다시 만들기: `capture_fx_gif.gd` 첫 줄 주석대로 장면마다 찍고 `python3 review/v080_step3b/make_gifs.py <프레임 폴더>`. 격납고는 `capture_hangar.gd`.

## 3. 레일건 변경

- 조준: 다른 무기처럼 가장 가까운 대상(황금 운석은 조금 뒤로 미룸, 펄스와 같은 규칙). 예전의 "가장 먼 적"과 "화면 밖 적은 안 노림" 규칙은 지움.
- 공격: 쏘는 순간 우주선에서 사거리(300) 끝까지 그은 선에 걸친 적·운석이 모두 맞음. 걸침 = 대상 중심과 선 사이 거리 ≤ 대상 반지름 + 굵기의 반(굵기 5픽셀, `Balance.WEAPONS` 레일건 `width`, 빛줄기 그림 굵기도 이 값). 따로 날아가는 탄 없음. 다중 포신이면 선이 여러 개지만 한 번 쏠 때 같은 대상은 한 번만.
- 레벨업 카드: 탄이 없어서 관통·궤도 관통에 더해 튕김(반사 코팅 탄)·연쇄 반사 매트릭스도 레일건에서 안 나오게 함(플라스마·빔과 같음).
- 효과: 빛줄기 시작점은 그릴 때마다 지금 총구(우주선 위치 + 반동 + 앞 10픽셀). 잔상은 쏜 방향·길이를 지키며 우주선과 같이 움직임. 충전 빛도 같은 총구 위치.
- 설명 글: "가까운 적 쪽 일직선을 한 번에 꿰뚫는 빛줄기" (weapon_names.md에도 바뀐 것 기록).
- 자동 테스트(`tests/test_weapons.gd`): 가까운 적을 노림 / 한 줄의 적·운석 4개 + 굵기 안에 걸친 것이 모두 같은 피해, 굵기 밖·사거리 밖은 안 맞음, 탄 0 / 다중 포신이어도 한 번만 / 이동 속도 최대로 움직이는 0.5초 동안 빛줄기 시작점 = 총구.
