# v0.8.0 5b단계: 진화 4개 다시 만들기 + 폰 화면 버그 2개 (2026-11-13, 맥)

사용자 결정(GAME_SPEC.md 11장 "진화 4개 다시 만들기", PLAN 21장): 회전 충각·연소 기뢰선·공명 파쇄·정지장 붕괴탄은 진화하면 판 흐름이 바뀌는 새 동작이 생겨야 한다. 연쇄 폭격·과충전 방전은 그대로.

## 진화 4개 새 동작 (5단계 수치는 그대로 쓰고 위에 얹음)

| 진화 | 새 동작 | 연출 |
|---|---|---|
| 회전 충각 | ① 4초마다 톱날 전부가 도는 반경의 3배(42 → 126)까지 휘어 날아갔다 1.3초 만에 돌아옴(부메랑, 날아가는 동안 피해 ×2.2) ② 이동 속도 70% 이상이면 톱날이 진행 방향 앞쪽 부채꼴로 모여 충각: 작은·중간 운석은 한 번에 부숨, 다른 적은 피해 ×4 (판정 +6) | 지난 프레임 위치로 그린 짧은 잔상 호(금 → 진홍, 부메랑 중 굵게 + 불티), 앞쪽 금빛 쐐기 |
| 연소 기뢰선 | ① 이어진 기뢰 하나가 터지면 선으로 이어진 이웃이 0.1초마다 줄줄이 터짐(도미노) ② 터진 자리마다 2초 불바다(초당 피해 300) ③ 선에 닿은 적이 타는 것은 그대로 | 선을 따라 달려가는 불길(흰·금 머리 + 주황 꼬리), 바닥에 일렁이는 불꽃 기둥 + 위로 뜨는 불티(경계선 없이 옅은 바탕) |
| 공명 파쇄 | ① 파동으로 부서진 운석이 그 자리에서 반경 40 공명 파동(큰 파동 피해 ×0.6)을 다시 뿜고, 그 파동으로 부서진 운석도 또 뿜음(세대 6까지, 큰 파동 하나에 24개까지) ② 파동으로 부서진 운석의 광물은 바로 우주선 쪽으로 끌려옴 ③ 작은·중간 운석 한 번에 + 광물 +1은 그대로, 큰 운석·다른 적 피해 ×2 → ×2.7 | 운석밭을 따라 번지는 작은 금빛 물결(세대가 높을수록 희게), 세대마다 2반음씩 오르는 광물 종소리(한 프레임에 가장 높은 것 하나, 몰림 상한) |
| 정지장 붕괴탄 | ① 자리 잡은 블랙홀이 둘레 140 안 적들의 가운데 쪽으로 초당 28 움직이며 끌어당김 ② 사라질 때 언 적마다 얼음 조각 4~6개가 사방으로 튀어, 블랙홀 밖 적을 맞히면 피해 150 + 1.5초 50% 느려짐(한꺼번에 48개까지) ③ 얼림·붕괴 피해 900은 그대로 | 움직이는 반대쪽으로 서리 꼬리(얼음 십자 + 흰·청록 점), 청백 얼음 조각 막대 |

- 모두 원 경계선 없음(불바다·물결은 옅은 바탕 + 끊어진 호·점), 정수 픽셀, 적 탄 아래 층(불바다·물결·불길은 적 아래, 얼음 조각·톱날·쐐기는 내 탄 층).
- 폰 성능 상한: 공명 파동 24개/큰 파동·6세대, 얼음 조각 48개, 불바다 12개, 도미노 불길·물결 그림 각 16개(`Juice.SUB_FX_MAX`).
- 카드 설명: 정지장 "적이 많은 쪽으로 움직이며 얼리고, 깨질 때 얼음 조각이 튐", 회전 충각 "4초마다 톱날이 멀리 날아갔다 돌아오고, 빠르면 앞쪽 충각", 연소 기뢰선 "이어진 기뢰가 줄줄이 터지고 자리마다 불바다", 공명 파쇄 "부서진 운석이 파동을 다시 뿜어 운석밭을 연쇄로 부숨". 전시관에서 만든 진화를 고르면 "이름 / 짧은 설명 (보조 무기 + 짝 스킬)".

## 세기 ([bot_dummy.md](bot_dummy.md), 시드 1~10, 20초, 적 등장·기본 무기 없음)

| 진화 | 표 A 허수아비 (5단계 표 4와 같은 방법) | 표 B 운석밭 (3:00 체력 운석 30개, 부서지면 새로) |
|---|---|---|
| 연쇄 폭격 (그대로) | ×3.51 | ×2.75 |
| 정지장 붕괴탄 | ×1.85 → **×3.00** | ×1.65 |
| 회전 충각 | ×3.80 → **×3.32** | ×2.23 |
| 연소 기뢰선 | ×2.14 → **×3.42** | ×1.47 |
| 과충전 방전 (그대로) | ×1.93 | ×2.84 |
| 공명 파쇄 | ×2.00 → **×2.70** | ×4.49 (부순 수 78 → 385) |

- 목표(표 A에서 4개 모두 ×2.5~×3.5) 맞춤. 표 A 허수아비는 부서지지 않는 황금 운석이라 "부서진 운석이 다시 파동"(공명)·"작은 운석 한 번에"(충각)가 안 보여서 표 B를 따로 쟀다.
- 6단계에서 볼 것: 공명 파쇄는 촘촘한 운석밭에서 매우 셈(×4.49), 연소 기뢰선·정지장은 운석밭에서 약함(×1.5~1.7). 과충전 방전은 표 A ×1.93으로 목표보다 낮음(이번엔 그대로 두라는 결정).

## 화면 버그 2개

1. 폰 전시관 진화 칸: 원인은 그림이 안 그려진 게 아니라, 폰은 칸이 한 줄 남짓만 보이는데 끄는 최대값이 줄 중간에서 멈춰 윗줄 틀은 위 머리줄에 가려지고 그 아래 이름 "?"만 떠 보였던 것. 고침: 손을 떼면 줄 맨 위에 멈추고(끈 쪽 다음 줄로, 조금 끌면 제자리), 최대값도 멈출 자리 중 하나로, 틀이 다 가려진 칸은 이름도 안 그림. 자동 테스트: 세 창 크기에서 모든 칸(발견 12 + 진화 6)이 어느 멈춤 자리에서 통째로 보이는지.
2. 폰 카드 줄바꿈: 조합법·진화 재료 줄은 이름 단위로만 줄을 바꾼다("유도 미사일 포드" / "+ 고폭 탄두 →", "진화 재료:" / "유도 미사일 포드", 둘째 덩어리도 안 들어가면 "기뢰 살포기 +" / "잔류 분사 궤적 →"). 카드 이름: 폰 카드 폭(190)에 안 들어가는 이름(정지장 붕괴탄 154, 잔류 분사 궤적 164px)이 있는 화면만 카드 폭을 그 이름에 맞게 최대 206까지 넓힘(평소 크기 약 73% 결정은 그대로). 자동 테스트: 진화 6 + 짝 스킬 6 카드가 PC·폰·작은 폰에서 이름 한 줄, 조합법·진화 재료가 위 형태 중 하나.

## ?fxtest 새 키 (배포 전 삭제)

- Shift+F: 촬영 모드(Shift+0)에 바깥(90~200) 7:00 체력 운석밭 켜고 끄기 (공명 연쇄·얼음 조각 장면)
- Shift+7: 이제 누를 때마다 6개 보조 무기를 차례로 5단계 + 짝 스킬로 맞춰 진화 카드 화면

## 검수 (넘기기 전에 하나씩 열어 봄)

- 폰 전시관(확대): 맨 위 → 둘째 줄 → 셋째 줄 → 진화 머리줄 + 첫 줄 → 진화 둘째 줄(공명 파쇄)까지 멈출 때마다 틀이 통째로 보이고, 이름만 떠 있는 칸 없음. 맨 아래에서는 아래에 빈 곳이 조금 남음. PC는 6칸씩 3줄, 진화 6개가 한 줄.
- 카드 12장(PC·폰, 확대): 이름 중간 줄바꿈 없음, 글자가 틀 안쪽 선과 겹치지 않음. 폰 "잔류 분사 궤적"은 카드가 넓어진 화면에서 양옆 여유 약 19px.
- GIF: 회전 충각(직진 때 앞쪽 쐐기 + 톱날 모임, 멈췄을 때 부메랑), 연소 기뢰선(이어진 기뢰가 이어진 프레임에서 차례로 터짐 + 불바다), 공명 파쇄(바깥 운석밭으로 금빛 물결이 번지고 광물이 끌려옴), 정지장(블랙홀이 움직이고 붕괴 때 청백 얼음 조각이 사방으로). 레벨업 카드 끼어듦 없음.
- 다시 찍은 것: ① 부메랑 잔상이 톱날 4개 꼬리가 이어져 원처럼 보임 → 잔상 14 → 7프레임. ② 정지장 얼음 조각이 뭉친 옆 적에 바로 맞아 안 보임 → 같은 붕괴에 맞은 적은 건너뛰게 + 촬영용 운석밭 체력을 7:00 체력으로. ③ 정지장 비교 그림이 블랙홀을 잘라냄 → 자르는 위치를 위로.
- 콘솔 오류 0 (모든 촬영).
