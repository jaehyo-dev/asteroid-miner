## 짝 스킬 5개 (짝 보조 무기를 가졌을 때만 카드에 나옴, 에픽·유니크, 최대 3번)

| 스킬 | 진화 전 효과 (에픽 / 유니크) | 진화 재료 |
|---|---|---|
| 냉각 응결탄 | 맞은 적 1초 30% / 40% 느려짐 (겹쳐 60%까지), 느려진 적에 청록 서리 점 | 블랙홀 발사기 |
| 관성 충각 | 이동 속도 70% 이상으로 부딪히면 작은·중간 운석을 몸으로 부숨(안 다침), 다른 적은 피해 150 / 300 | 궤도 톱날 |
| 잔류 분사 궤적 | 지나간 자리 1.5초 불꽃, 초당 피해 80 / 120 | 기뢰 살포기 |
| 전하 축적 탄 | 같은 적을 맞힐수록 +8% / +12%씩 (5번까지), 쌓인 수만큼 적 위 청록 점 | 방전 코일 |
| 광맥 공명기 | 운석이 부서져 광물이 떨어지면 둘레 34에 충격파 60 / 100 (충격파로 부서진 운석은 다시 안 냄) | 채굴 펄스 |
| 고폭 탄두 (원래 카드) | 그대로. 유도 미사일 포드를 가지면 뽑기 목록에 2번 들어감 | 유도 미사일 포드 |

## 진화 6개 (5단계 수치 그대로 + 동작 하나 더)

| 진화 | 더해진 동작 | 연출 (5단계 위에 얹음) |
|---|---|---|
| 연쇄 폭격 | 미사일 폭발 0.12초 뒤 옆 적(70 안)에서 다시 터짐, 3번까지, 매번 피해 ×0.8 | 진홍 빛 탄두·불티 꼬리, 폭발 사이 진홍·금 불줄기, 진홍 폭발 |
| 정지장 붕괴탄 | 블랙홀 안 적이 얼어 스스로 못 움직임, 끝날 때 반경 1.2배 안에 피해 900 | 가운데를 도는 얼음 조각, 언 적에 얼음 십자, 끝에 흰 번쩍 + 얼음 조각이 튀는 서리 안개 |
| 회전 충각 | 톱날 반지름 5 → 8, 도는 반경 +6, 최고 속도에서 피해 ×2.5·도는 속도 ×1.75 | 톱니 10개 진홍·금, 빠를수록 긴 잔상, 뒤로 튀는 불티 |
| 연소 기뢰선 | 켜진 기뢰를 놓인 순서대로 이웃끼리(130 안) 불타는 선으로 잇고, 선에 닿은 적 초당 피해 250 | 빛 번짐 + 주황 심지 선, 선을 따라 흐르는 불티 |
| 과충전 방전 | 번개가 맞힌 수가 20 쌓이면 우주선 둘레 200 안 모두에게 피해 600 | 충전만큼 우주선 둘레를 도는 불꽃 점, 방전 때 흰 번쩍 + 맞은 적까지 굵은 번개 12갈래 + 퍼지는 청록 점 안개 |
| 공명 파쇄 | 파동에 닿은 작은·중간 운석(황금 아님)은 한 번에 부서지고 광물 +1, 큰 운석·다른 적은 피해 ×2 | 운석이 흰 번쩍 + 금빛 조각으로 터짐 |

원칙: 원 경계선 대신 끊어진 호·점 안개, 정수 픽셀 위치, 모두 적 탄 아래 층(WorldView 순서 그대로), 효과 목록마다 `Juice.SUB_FX_MAX`(16) 상한. 판 화면 칸은 진화 아이콘 + 단계 점 대신 진홍·금 점이 흐른다.

## 진화 카드

- 진화 조건이 맞으면 다음 레벨업 화면에 1장 확정(수치 강화 → 보조 무기 → 효과 카드 순으로 한 칸을 바꿈). 고르지 않으면 다음 화면에도 또 나온다. 다시 뽑아도 남는다.
- 등급 "진화"(6번째): 진홍·자두색 금속 틀 + 금빛 발광 부분, 네 모서리 장식·큰 날개, 진홍·금 빛 띠와 후광(레전드리 무지개와 구분). 고른 표시 테두리는 없음(기존 규칙).
- 등장: 뒷면이 내려온 뒤 0.75초 동안 보조 무기·짝 스킬 아이콘이 양쪽에서 가운데로 빨려 들어가 겹치며 흰빛 → 뒤집혀 진화 아이콘, 가장 큰 폭발(파티클 160·빛줄기 32)·흔들림 3.
- 글자: 꼬리표 "진화", 작은 진홍 줄 "<보조 무기> + <짝 스킬> →", 이름(금), 효과. 짝 스킬 카드는 설명 아래 작은 주황 줄 "진화 재료: <보조 무기>".
- 소리 후보 (`?fxtest` V 등장, B 고를 때, 누르면 바로 들림, 구석 글자에 번호): 등장 1 = 레전드리 카드 소리(기본), 2 = 낮은 모으기 → 금속판 쿵 + 낮은 레전드리 울림, 3 = 높은 마림바 → 도·미·솔·도 종 화음. 고를 때 1 = 카드 고르기(기본), 2 = 카드 고르기 + 금속판 쿵, 3 = 카드 고르기 + 높은 광물 종 두 번.

## 전시관 진화 도감

- 발견 칸 아래 "진화 도감 n / 6" 줄 + 진화 칸 6개(발견 보상 수에는 세지 않음). 만든 것은 금 틀(전설 틀) + 진화 그림 + 진홍 이름, 고르면 "이름 / 보조 무기 + 짝 스킬". 못 만든 것은 꺼진 틀 + 검은 실루엣 + "?", 고르면 "??? 힌트: <보조 무기> + ?".
- 진화 카드를 고르는 순간 저장한다(그 판에서 죽어도 남음). `?fxtest` Alt+Shift+1~6도 기록한다.

## ?fxtest 새 키 (배포 전 삭제)

- Alt(Ctrl·Cmd)+Shift+1~6: 그 보조 무기 하나만 5단계 + 짝 스킬 → 바로 진화 (도감 기록)
- Shift+7: 진화 카드 화면 (진화 안 한 보조 무기를 5단계 + 짝 스킬로 맞추고 레벨업, 옆 칸에 그 짝 스킬 카드)
- V / B: 진화 카드 등장 / 고르기 소리 후보 1 → 2 → 3
- 판 중 구석 안내에 적었다. 레벨업 화면이 떠 있는 동안은 구석 안내를 숨긴다(카드·버튼을 가려서).

## 봇 ([bot_table.md](bot_table.md)) — 수치는 바꾸지 않음

- 표 1(10분, 진화 우선): 지금 5분 곡선에서는 봇이 3분 40초 안팎에 쓰러져 보조 무기가 평균 1단계 안팎. **진화까지 간 판은 180판 중 1판(채굴 펄스, 3:45)**. 그래서 표 2~4를 따로 쟀다.
- 표 2(처음부터 5단계 + 짝 스킬 vs 진화, 3분)·표 3(기본 무기 끔): 처치 +1~9%(톱날만 +42%). 처치 수가 적 등장 수에 막혀(봇이 거의 다 잡음) 세기 차이가 잘 안 보인다.
- 표 4(허수아비 12개, 20초 피해 합): **진화가 5단계보다 ×1.85~×3.80**. 연쇄 폭격 ×3.51, 정지장 ×1.85, 회전 충각 ×3.80, 연소 기뢰선 ×2.14, 과충전 ×1.93, 공명 파쇄 ×2.00 (공명 파쇄는 황금 운석만 둬서 "한 번에 부숨"이 아닌 피해 ×2만 잰 값).

제안 (6단계 10분 곡선에서 다시 잰 뒤 정함)
1. 첫 진화가 흐름표(7:00~7:40)에 오도록: 10분 곡선 + 가진 보조 무기 강화 카드 가중치를 올리는 쪽. 지금 곡선으로는 진화에 못 감.
2. 연쇄 폭격·회전 충각(×3.5~3.8)과 정지장(×1.85)의 차이가 크다: 정지장 붕괴 피해 900 → 1300 쯤, 또는 연쇄 3번 → 2번을 6단계에서 함께 본다.

## 검수 (넘기기 전에 하나씩 열어 봄)

- GIF 12개: 진화 6개 모두 더해진 동작이 보인다(연쇄 불줄기·진홍 폭발, 얼음 조각·붕괴 서리, 큰 톱날·긴 잔상, 기뢰 사이 불타는 선, 화면 절반 번개, 운석 금빛 파쇄). 레벨업 카드 끼어듦 없음(촬영 모드). 톱날·기뢰 장면은 움직이며 부딪혀 붉은 피격 번쩍임이 몇 장 섞인다(비교 그림은 번쩍임 없는 프레임 `picks.json`).
- 다시 찍은 것: 연소 기뢰선 — 처음엔 기뢰 사이 거리(최고 속도 96픽셀)가 잇는 거리 70보다 멀어 곧게 갈 때 선이 안 생김(봇 표 4에서 ×1.00로 발견) → 130으로 고친 뒤 다시 찍음. 전시관 진화 그림이 흰·검은 네모로 나옴(그리기 중 load한 그림이 풀림) → 그림을 붙잡아 두게 고친 뒤 다시 찍음. 진화 카드 조합법이 이름과 같은 금색이라 헷갈림 → 조합법 진홍으로. 구석 안내가 카드 버튼을 가림 → 레벨업 중 숨김.
- 카드·전시관·판 화면: 깨진 글자·잘린 그림·칸 밖 글자 없음. 폰 진화 카드는 조합법 2줄, 짝 스킬 카드 "진화 재료" 2줄로 칸 안. 폰 전시관은 끝까지 끌면 진화 마지막 줄까지 보이고 힌트 줄이 한 줄에 들어감.
- 콘솔 오류 0 (모든 촬영).
