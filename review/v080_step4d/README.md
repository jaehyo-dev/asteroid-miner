## ?fxtest 숨은 키 (v0.8.0 배포 전에 지움)

- `M`: 기뢰 후보 1 → 2 → 3 (구석 글자에 "기뢰 후보 n")
- `Shift+M`: 우주선 자리에 후보 비교판 (mine_sheet.png의 원본 화면)
- `Shift+8`: 촬영 모드(Shift+0)에서 적 탄을 우주선 옆으로 스쳐 지나가게 섞기
- 기뢰 5단계만 보기: `Alt+4`를 세 번
