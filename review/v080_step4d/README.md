# v0.8.0 4d단계: 기뢰 몸체 후보 3개 확인 자료 (2026-11-13, 맥)

웹 빌드(`?fxtest`)를 Playwright headless(Chromium)로 열어 찍었다. Godot 창은 띄우지 않았다.
기뢰의 동작·피해·범위·폭발 연출·터질 때 범위 번쩍임은 그대로이고, 몸체 그림(`SubWeaponFx.MINE_MAPS` 픽셀 지도)만 바꿨다.

- `mine_sheet.png`: 후보 1~3 × 1·3·5단계, 칸마다 왼쪽 1배(640x360 기준) + 오른쪽 4배. 오른쪽 칸은 비교용 적 탄(심연의 포격·고대 경비선)과 내 탄(펄스 연사포). 불빛은 켜진 상태.
- `gif/mine_look<1|2|3>.gif`: 후보별 5단계 기뢰 + 펄스 연사포, 적 탄이 우주선 옆을 스쳐 지나가는 장면. 1280x720(출격 화면 2배), 4.0초(60장).
- 다시 만들기: `python3 -m http.server 8766 --directory build/web` → `NODE_PATH=… FRAMES=<폴더> node review/v080_step4d/capture_web.cjs gallery look1 look2 look3` → `python3 review/v080_step4d/make_sheet.py <폴더>`

## 후보 (모두 청록·금빛, 빨간 불빛은 가운데 1픽셀 점만 깜빡임)

| 후보 | 1단계 | 3단계 | 5단계 |
|---|---|---|---|
| 1 둥근 몸체 + 가시 | 7x7 둥근 몸체 | + 위아래·양옆 T자 금빛 돌기 4개 (11x11) | 9x9 몸체 + 금빛 테 가운데 + 돌기 8개 (13x13) |
| 2 육각 판 | 11x9 육각 판 (위 밝은 면, 아래 짙은 면) | + 꼭짓점 금빛 가시 6개 (15x11) | 13x11 판 + 육각 금빛 가운데 + 가시 6개 (17x13) |
| 3 날개 달린 위성 | 5x5 몸체 + 양옆 태양판 (11x5) | + 위아래 안테나·대각 가시 (11x9) | 7x7 몸체 + 금빛 테 + 줄무늬 태양판 + 가시 (15x11) |

## ?fxtest 숨은 키 (v0.8.0 배포 전에 지움)

- `M`: 기뢰 후보 1 → 2 → 3 (구석 글자에 "기뢰 후보 n")
- `Shift+M`: 우주선 자리에 후보 비교판 (mine_sheet.png의 원본 화면)
- `Shift+8`: 촬영 모드(Shift+0)에서 적 탄을 우주선 옆으로 스쳐 지나가게 섞기
- 기뢰 5단계만 보기: `Alt+4`를 세 번

## 검수 (하나씩 열어 봄)

- mine_sheet: 9칸 모두 모양이 보이고, 1배에서도 후보 1(둥근 기뢰)·3(넓은 위성)은 실루엣이 또렷. 후보 2는 1배에서 둥근 판에 가깝게 보이고 4배에서야 육각이 읽힌다.
- GIF 3개: 5단계 기뢰가 길을 따라 깔리고, 빨갛게 빛나는 적 탄과 색·모양이 겹치지 않는다. 불빛은 점으로만 깜빡인다.
- 처음 시안에서 흰 끝 가시가 반짝이(별)처럼 보이고 후보 2가 알약 모양이라, 가시를 금빛 T자 돌기로, 육각을 1:1 비탈로 다시 그렸다.
- 후보 1 GIF는 받은 프레임이 81장/4.6초로 적어(headless 부하) 일부 같은 그림이 이어질 수 있다. 콘솔 오류 0.
- 우주선 곁을 지나는 청록 광물(희귀)도 비슷한 색이라, 고를 때 광물과 헷갈리지 않는지도 같이 봐 주면 좋다.
