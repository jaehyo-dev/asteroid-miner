# 격납고 "기본 무기 고르기" 시안 3개 (v0.8.0 1단계, 게임에 적용 안 함)

바탕은 실제 격납고 창 캡처(`base_*.png`)이고, 바뀌는 곳만 같은 2배 격자·Galmuri11 12px로 덮어 그렸어요.
표본 상태: 펄스 연사포 = 장착, 산탄포·레일건 = 해금, 플라스마 대포·채굴 빔 = 잠김. 가격·공격력(C)은 임시.
무기 아이콘은 펄스 연사포만 실제 그림이고 나머지 4개는 시안용 임시 그림이에요(나중에 Codex로 다시 그림).

## A. 설명 패널 안 목록 (산탄포를 고른 상태)
- 구조: 오른쪽 설명 패널이 무기 5줄 목록으로 바뀌고, 고른 줄만 펼쳐져 설명·막대 3개·장착 버튼이 보여요. 우주선과 능력치는 그대로예요.
- 장점: 화면 하나만 바뀌어 만들기 가장 쉬워요. 우주선을 보면서 무기를 고를 수 있어요.
- 단점: PC도 패널이 꽉 차요(무기가 6개 넘으면 스크롤 필요). 폰은 132칸 패널에 안 들어가 가운데 우주선 자리까지 넓혀야 하고, 줄에 해금 가격을 넣을 자리가 없어요(자물쇠만 보여요).

## B. 아래 줄 탭 (플라스마 대포를 고른 상태)
- 구조: 전투기 칸 줄 위에 [전투기 | 기본 무기] 탭, 무기 탭이면 아래 줄이 무기 카드 5개. 오른쪽 패널은 고른 무기 자세히(막대 3개, 잠김이면 "연구소에서 해금 · 가격" + "연구소로 ▶" 버튼).
- 장점: 전투기 고르기와 같은 자리·같은 조작이라 배우기 쉬워요. 5개를 한눈에 비교하고, 잠긴 카드에서 바로 연구소로 이어져요.
- 단점: 폰은 탭을 넣으려고 카드 줄이 22칸으로 낮아져 카드에 이름이 안 들어가요(아이콘 + 상태/가격만, 이름은 패널). 폰 카드는 "장착 중" 대신 "사용"으로 줄였어요.

## C. 무기 전용 화면 (레일건을 고른 상태)
- 구조: "◀ 전투기"로 돌아가는 별도 화면. 가운데 받침에 무기를 3배(폰 2배)로 띄우고, 왼쪽은 무기 능력치 4개(사거리·연사·채굴량·공격력, 5칸), 아래 무기 카드 5개, 오른쪽 설명 + 지금 장착 + 장착 버튼.
- 장점: 무기가 주인공이라 가장 멋있고, 공격력까지 4가지를 크게 비교해요. 보조 무기·무기 강화가 생기면 이 화면을 늘리기 좋아요.
- 단점: 화면이 하나 더 생기고(오가는 조작 1번 추가), 무기에 맞춘 받침 연출(회전 등)을 새로 만들어야 해요. 폰 카드는 이름 대신 상태·가격만 보여요.
